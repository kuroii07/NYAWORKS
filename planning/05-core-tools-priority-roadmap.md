# NYAWORKS 核心工具优先开发路线

日期：2026-09-29
状态：已确认，作为后续功能开发的优先级依据

## 1. 当前判断

NYAWORKS 当前已经具备主题、语言、首页布局、设置中心、AI 设置、资源页基础、Action Registry 与 Nya Pie 技术验证底座，但真正可在 After Effects 中执行的核心创作工具仍然不足。

Nya Pie 本质上是 NYAWORKS Action 的快捷调用入口，不是独立功能库。如果在核心 Action 数量不足时继续开发正式 Pie UI、Pie Editor、多 Profile 和智能上下文，只会先形成一个完整但缺少可用内容的外壳。

因此确定：

- 保留现有 Nya Pie P0 Runtime 与 NyaLauncher P1 技术成果；
- 暂停正式 Nya Pie UI、Pie Editor、多 Profile 和 Context Aware Pie；
- 后续开发主线切换到 NYAWORKS 核心工具；
- 每个新工具从第一天开始接入统一 Action Registry，确保未来可以同时被首页、全局搜索、功能页、快捷键和 Nya Pie 调用。

## 2. 统一工具调用架构

```text
Action Registry
├─ 首页按钮
├─ 全局搜索
├─ Banner 工具入口
├─ 功能页
├─ 快捷键
└─ Nya Pie
```

每个可执行工具必须包含：

- `NyaActionDefinition`：ID、标题、说明、图标、分类、运行要求、Pie 支持和撤销策略；
- `ActionAvailability`：当前 AE 上下文中是否可执行，以及不可执行原因；
- `ActionResult`：成功状态、用户提示、返回数据和错误；
- Context Engine：读取当前合成、选择层、关键帧和宿主状态；
- Action Runner：统一执行、错误处理和结果反馈；
- Host Executor：实际调用 ExtendScript / AE Host 能力。

不得为首页、搜索或 Nya Pie 分别维护独立工具目录。

## 3. 第一阶段：完成四套首页九宫格

### 3.1 锚点九宫格

- 完成九点锚点定位；
- 移动锚点后保持图层画面位置；
- 支持普通 2D 与 3D 图层；
- 检查父级、旋转、缩放、关键帧、表达式和锁定图层；
- 补齐真实 AE 宿主验收与错误提示。

### 3.2 对齐九宫格

- 单选图层时默认按合成边界对齐；
- 多选图层时默认按选区联合边界对齐；
- 多选时按住 Alt / Option 或 Shift 强制按合成边界对齐；
- 保留 6 个图层对齐与 3 个文字段落对齐；
- 检查 2D / 3D、父级、旋转、缩放、锁定、关键帧、表达式和文字框；
- 补齐真实 AE 宿主验收与失败状态。

### 3.3 新建图层九宫格

- 没有选中图层时，按 AE 默认规则创建到时间轴顶部；
- 选中一个或多个图层时，创建到最上方选中层的上方；
- 单层选中时继承其入点、出点和持续时间；
- 多层选中时根据已确认规则计算新图层时间范围；
- 空对象自动作为选中图层的父级；
- 摄像机默认创建 35mm Camera，并自动创建开启 3D 的控制空对象；
- 使用 Alt / Ctrl / Shift + 点击承载对应图层的扩展动作；
- 所有创建操作进入统一撤销组。

### 3.4 选择与显示九宫格

- 按文字、形状、固态层、空对象、摄像机、灯光等类型选择；
- 全选、反选和取消选择；
- 独显、显示、隐藏；
- 锁定和解锁；
- 删除或调整选择后保持可预测的时间轴状态；
- 只保留高频且比 AE 原生操作更有效的组合动作。

## 4. 第二阶段：高价值增强工具

优先开发 AE 原生操作不够高效、需要多步操作或适合批量处理的功能：

- 批量重命名与智能编号；
- 智能预合成；
- 批量调整图层入点、出点和持续时间；
- 自动裁切合成或图层；
- 图层分布与智能间距；
- 属性批量复制、粘贴和链接；
- 关键帧错帧与序列排列；
- 表达式生成、检查和修复；
- 项目整理、缺失资源和重复素材处理。

AE 已经具备足够快捷入口的简单功能不优先开发。例如普通 Easy Ease 已可通过 F9 完成，只有在提供更强的批量、参数化或上下文增强能力时才进入 NYAWORKS。

## 5. 每项功能的完成标准

一个工具只有同时满足以下条件，才可以标记为完成：

1. Action Definition 已加入统一 Registry；
2. Context Engine 能正确判断可用状态；
3. Host Executor 使用稳定 API 或 `matchName`，不依赖中英文显示名；
4. 修改 AE 项目内容时使用撤销组；
5. 首页、搜索和功能页调用同一个 Action；
6. 自动化测试通过；
7. 真实 AE 中完成目标场景验收；
8. 中文、繁體中文、English、日本語、한국어文案同步；
9. 错误信息能说明失败原因；
10. 不破坏已确认的主题、语言、设置和首页交互。

## 6. 恢复正式 Nya Pie 开发的门槛

达到以下条件后再恢复正式 Nya Pie：

- 至少有 20–30 个稳定可执行 Action；
- 至少覆盖 4 个高频工作流；
- 锚点、对齐、新建、选择四套九宫格完成真实 AE 验收；
- 首页、全局搜索和功能页已通过统一 Action Registry 调用；
- NyaLauncher P1 的鼠标定位、无边框、焦点和连续呼出通过真实 AE 验收。

恢复后的开发顺序：

1. 正式八方向 Runtime；
2. 单个默认 Pie；
3. Action 选择器；
4. 拖拽式 Pie Editor；
5. 布局导入与导出；
6. 多 Profile；
7. Context Aware Pie；
8. Command Palette。

## 7. 当前执行顺序

```text
锚点正式落地
→ 对齐正式落地
→ 新建图层九宫格
→ 选择与显示九宫格
→ 第一批高价值增强工具
→ 恢复正式 Nya Pie
```

Nya Pie 和 NyaLauncher 在核心工具开发期间只进行必要的兼容维护，不扩展正式视觉、编辑器或高级功能。
