# NYAWORKS 首页布局系统设计

日期：2026-09-24
状态：已确认

## 1. 目标

把首页下半部分从单一固定工具列表升级为可切换、可保存、可编辑的布局系统。

“布局”不是图标数量限制，而是一套完整的首页工具组配置。切换布局时，首页布局名称、工具组顺序、工具组名称、工具组图标以及组内工具同时切换。

## 2. 页面边界

以下内容不属于布局，保持固定：

- 全局搜索
- 首页 Banner
- “新建 / 选择”九宫格
- “锚点 / 对齐”九宫格

布局只管理九宫格下方的工具组区域。

首页原“我的快捷工具”标题改为当前布局名称，例如：

- 创作通用
- MG 动画
- 文字排版
- 我的常用

## 3. 布局类型

### 3.1 内置布局

第一版提供内置布局“创作通用”：

- 默认显示 5 个工具组。
- 每个工具组固定 8 个工具位，默认 7 个工具加 1 个“＋”入口。
- 保留原首页完整工具内容，不再按 8 / 12 / 16 / 20 截断。
- 内置布局不可重命名、不可删除。
- 用户尝试编辑内置布局时，复制为新的自定义布局后再编辑，原版始终保留。

未来可以继续增加其他内置布局，但本轮只实现“创作通用”。

### 3.2 自定义布局

用户可以：

- 从当前布局复制创建。
- 创建空白布局。
- 输入布局名称。
- 重命名布局。
- 删除布局。
- 调整工具组顺序。
- 新建、复制、重命名、删除工具组。
- 修改工具组图标。
- 替换、移除或重新添加组内工具。

每个工具组固定 8 个工具位。移除或移出工具后，其余工具自动前移，空位集中到末尾并显示“＋”入口。

## 4. 布局选择与管理

首页设置顶部增加“当前布局”选择栏：

```text
[ 创作通用 ▼ ]  [＋]  [···]
```

- 下拉菜单显示内置布局和用户自定义布局。
- `＋` 打开 NYAWORKS 自定义“新建布局”窗口。
- `···` 打开当前布局操作菜单。
- 右键点击布局选择框也打开同一个操作菜单。
- 所有纯图标按钮必须提供 Tooltip。

当前布局操作菜单：

- 复制当前布局
- 重命名
- 删除

当选中内置布局时：

- 复制可用。
- 重命名、删除置灰。

导入、导出和恢复默认保留在布局设置底部的紧凑图标操作栏中：

- 导入布局
- 导出当前布局
- 恢复默认布局状态

导入布局始终创建新的自定义布局，不静默覆盖同名布局。同名时提示用户修改名称。

## 5. 新建与重命名输入

不调用 AE 原生输入框、浏览器 `prompt()` 或 Windows 原生对话框。

统一使用 NYAWORKS 自定义弹窗：

- 布局名称输入框
- 创建方式选择：
  - 复制当前布局，默认选中
  - 创建空白布局
- 确认与取消按钮
- 自动聚焦输入框
- 支持 Enter 确认、Esc 取消
- 空名称不可提交
- 自动移除首尾空格
- 同名时显示项目风格的行内错误提示
- 名称建议限制为 1–24 个字符

工具组重命名使用同一套自定义输入组件，名称建议限制为 1–16 个字符。

## 6. 工具组编辑

工具组列表结构：

```text
拖拽手柄｜工具组图标｜工具组名称｜显示/隐藏｜展开
```

工具组区域标题右侧增加小型 `＋` 图标，用于新建工具组。

每个工具组支持：

- 拖拽排序。
- 上移、下移作为键盘及兼容性备用操作。
- 显示或隐藏。
- 展开 8 个工具位。
- 右键或 `···` 菜单：
  - 重命名
  - 修改图标
  - 复制工具组
  - 删除工具组

删除工具组必须使用 NYAWORKS 确认弹窗。内置布局进入编辑前先复制，因此不会直接破坏内置数据。

## 7. 工具位编辑

每个工具组始终渲染 8 个工具位：

- 已绑定：显示工具图标。
- 空位：显示“＋”图标。
- 左键已绑定工具位：打开工具选择器，用于替换。
- 左键空位：打开工具选择器，用于添加。
- 右键已绑定工具位：显示“替换”和“移除”。
- 拖拽工具位：调整当前工具组内部顺序，也可以移动到其他未满 8 个工具的工具组。
- 目标工具组已满 8 个工具时显示禁止反馈，不提交移动。
- 拖拽使用 Pointer Events，自定义浮层替代浏览器原生鬼影；原位置保留虚线占位，目标位置高亮，靠近滚动区域边缘时自动滚动，按 Esc 取消。
- 工具组排序只能从六点手柄开始拖动，放下后才保存排序；相邻项使用短时归位动画。

工具选择器使用 NYAWORKS 自定义窗口，并从统一工具注册表读取内容：

- 支持搜索。
- 按功能页分类。
- 显示图标、名称与简短说明。
- 尚未真正接入的脚本、预设和资源不得伪装成可执行工具。
- 导入布局遇到未知工具 ID 时，将该位置显示为空位并给出提示。

## 8. 工具组图标选择

修改工具组图标时打开紧凑的项目风格图标选择器：

- 使用项目现有的统一线性图标库。
- 图标随主题色变化。
- 支持搜索或按类别浏览。
- 不允许上传任意位图作为第一版功能。

内置“创作通用”的默认图标：

- 合成与项目：文件夹
- 图层操作：图层堆叠
- 动画与时间：曲线
- 文字与图形：文字 T
- 效果与预设：FX 或魔法棒

## 9. 数据结构

布局存储为独立实体：

```ts
interface HomeLayout {
  id: string;
  name: string;
  kind: "built-in" | "custom";
  groups: HomeLayoutGroup[];
  createdAt: string;
  updatedAt: string;
}

interface HomeLayoutGroup {
  id: string;
  name: string;
  iconId: string;
  visible: boolean;
  toolSlots: Array<string | null>; // 始终为 7 项
}
```

首页设置保存：

- 当前布局 ID
- 自定义布局集合
- 九宫格默认模式
- 是否记住九宫格上次模式

删除上一版错误设计中的：

- 固定工具数量
- 自定义快捷位数量
- 全局隐藏工具列表

工具的显示、删除和顺序改由每个布局自己的 7 格工具位决定。

## 10. 导入与导出

布局 JSON 包含：

- Schema 版本
- 产品标识
- 布局名称
- 工具组结构
- 工具组图标
- 每组 8 个工具位

不包含：

- 主题
- 语言
- API Key
- 授权信息
- 通用设置
- 九宫格当前临时切换状态

导入时必须校验：

- 产品标识与 Schema 版本
- 布局名称
- 工具组结构
- 每组工具位数量
- 图标 ID 与工具 ID

损坏文件不写入本地存储，并显示明确错误。

## 11. 国际化与视觉

- 新增文案同步支持简体中文、繁体中文、英文、日文、韩文。
- 输入框、弹窗、菜单、下拉框继续复用已确认的 NYAWORKS 视觉样式。
- 下拉展开宽度不得超过触发框边界。
- 图标按钮保持紧凑，不使用长文字按钮占据横向空间。
- 默认约 493px 面板宽度下不得出现横向滚动。

## 12. 迁移策略

当前尚未发布的“固定工具数量 / 自定义快捷位”实现直接替换，不作为正式用户数据迁移来源。

已有首页九宫格设置继续保留：

- 新建 / 选择默认模式
- 锚点 / 对齐默认模式
- 记住上次模式

旧的工具组顺序和显隐设置可用于初始化一个自定义布局；如果数据不完整，则安全回退到内置“创作通用”。

## 13. 验收标准

- 默认打开“创作通用”，首页完整显示 5 个工具组，每组 8 个工具位，其中第 8 格默认显示“＋”。
- 首页标题显示当前布局名称。
- 首页“编辑”直达首页设置。
- 编辑内置布局不会破坏原版。
- 可以创建空白布局或复制当前布局。
- 可以切换、复制、重命名和删除自定义布局。
- 可以新建、复制、重命名、换图标、排序和删除工具组。
- 每个工具组始终保持 8 个工具位。
- 可以添加、替换、移除、组内排序和跨工具组移动工具位；删除后自动前移，满组拒绝放入。
- 拖拽具有浮层、占位、目标反馈、短时归位动画、边缘自动滚动和 Esc 取消。
- 导入导出能够还原同一布局。
- 五种语言下无明显文字溢出。
- 默认面板宽度无横向滚动。
- 主题、语言、通用设置和关于页行为不受影响。
- 浏览器验证与真实 AE CEP 验收分别记录，不混为一谈。
