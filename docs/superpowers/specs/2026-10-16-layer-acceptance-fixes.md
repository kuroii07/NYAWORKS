# R02 / R04 / R05 修订范围

用户在 2026-10-16 明确确认 R01 调整层、R03 默认预合成通过；本轮保留这两项行为及四形状、摄像机的参数/FFX。

## 按钮与修饰键

| 入口 | 行为 |
| --- | --- |
| 灯光普通点击 / Alt / Ctrl / Shift | 点光 / 聚光 / 平行光 / 环境光（Ambient，沿用当前类型）；新层按具体类型及面板语言命名，同类型重名递增 |
| 预合成普通点击 | 保留已确认行为：一起预合成，移动全部属性，匹配选层时间范围 |
| Alt 预合成 | 裁切边界并保持画面位置。直接改变合成尺寸的旧算法不再用于任意 3D 图层；不支持安全保留的场景在修改前明确拒绝 |
| Ctrl 预合成 | 每个选层分别预合成，每项匹配自身时间；处理后选中全部新预合成层 |
| Shift 预合成 | 一起预合成并移动全部属性；保留 AE 原生完整合成时长，与普通点击的自动匹配时长区分 |
| 多个修饰键 / 旧 settings 模式 | 不再打开原生合成设置窗口；前端组合键沿用默认操作，旧 settings payload 在修改前拒绝 |
| 解预合成 | 完整提取所有内部图层后才移除当前外层；保留项目中的源合成，避免破坏其他使用者。失败撤销本次新增层并恢复选择；恢复不完整时明确要求 Undo |

## 问题与验证

- 环境光无可写空间属性：不再对 Ambient 写 Position / Point of Interest；其他类型仅写适用属性，创建后失败需移除新增灯光。
- 灯光名称：为四类灯光增加五语言名称，旧层不重命名。
- 时间：读取并保存 startTime/inPoint/outPoint 后再设置，避免 startTime 联动引发二次偏移。
- 裁切：测试必须包含真实内部层，而不能像旧模型一样让 precompose 返回空合成；投影空间与图层坐标不能混用。
- 解预合成：用真实增删/重排的集合、联动时间、无返回值 copyToComp 和后续失败模型验证；按操作前集合识别并清理新增层，不能仅吞掉 remove 异常。
- 回归先证明失败，再修改；类型/构建/专项检查与用户实际 AE 结果分开记录。本轮不启动或操作 AE，不运行诊断探针。
