# NYAWORKS 全局搜索与 Banner 工具工作区设计

日期：2026-09-26  
状态：待用户评审，评审通过后进入实现计划

## 1. 目标

将首页顶部的全局搜索和 Banner 从视觉占位升级为两个互相配合、职责清晰的功能：

```text
全局搜索：找到当前 NYAWORKS 与 AE 环境中可用的工具和资源
Banner：默认显示品牌 Banner，也可以临时替换为一个重点工具面板
下方九宫格：继续承担固定的常用工具快捷操作
```

全局搜索不只搜索首页已经配置的工具，还要覆盖：

- NYAWORKS 内置工具；
- 当前 AE 版本可访问的脚本与面板来源；
- 资源设置页添加并成功索引的本地脚本、预设和表达式资源；
- 当前运行 AE 已加载的内置效果和第三方效果。

Banner 不增加第二套九宫格。它的默认内容是品牌 Banner；用户在 Banner 上右键选择一个工具后，Banner 区域替换为该工具的轻量操作面板。

## 2. 产品边界

### 2.1 首页职责分工

- 顶部全局搜索：跨工具、脚本、预设、效果和资源进行查找，并根据资源类型执行默认动作。
- Banner：展示品牌内容或用户临时选择的一个工具工作区；不承担资源浏览，不承担工具组排序。
- 下方九宫格与工具组：保留现有固定快捷工具、拖拽排序、添加、替换和右键操作；本次不得因搜索或 Banner 改造而改变其布局和数据。

### 2.2 当前 AE 版本规则

- 效果列表只来自当前打开并连接的 AE 宿主。
- 默认脚本来源只使用当前宿主版本识别出的路径。
- 不自动扫描电脑上其他版本的 AE。
- 资源设置页中的自定义目录可进入索引，但仍需遵守现有资源类型和来源规则。
- 浏览器开发环境没有真实 AE 时，允许使用明确标记的 fixture 数据；不得把 fixture 当成真实宿主能力。

### 2.3 第一阶段范围

第一阶段实现：

1. 首页搜索框输入、浮层、键盘操作和双击执行；
2. NYAWORKS 内置工具、本地索引脚本/预设/表达式、当前 AE 效果的统一搜索模型；
3. Banner 默认状态、右键工具选择、工具面板替换和恢复默认；
4. 搜索结果与 Banner 的联动；需要参数的内置工具可以在 Banner 中打开。

明确不包含：

- Banner 内第二套九宫格；
- 自动轮播或定时替换 Banner；
- 首页直接展示完整资源库目录、路径和预览；
- 将所有脚本、效果塞进 Banner 右键菜单；
- 表达式的复杂编辑器；
- 云端搜索、云端工具推荐和后台管理。

## 3. 全局搜索设计

### 3.1 入口与显示方式

入口为首页顶部现有搜索框，支持：

- 左键聚焦输入；
- `Ctrl + K`（Windows）或 `⌘ K`（macOS）打开并聚焦；
- `Esc` 关闭结果浮层并恢复焦点上下文。

结果使用绝对定位浮层，不撑开首页内容，不推动 Banner 或下方九宫格。浮层应在默认、中、小三档密度下保持视口内可滚动。

### 3.2 结果信息密度

每一条结果只显示必要信息：

- 图标；
- 名称。

结果按类型分组，分组标题负责表达类别：

```text
工具
  图层对齐
  锚点设置

脚本
  合成整理.jsx

预设
  快速发光.ffx

效果
  Gaussian Blur
```

默认不显示来源、路径、简短说明、可用状态、单独操作按钮或“在 Banner 中打开”按钮。若同名结果必须区分，只增加最短的后缀，例如 `Gaussian Blur · AE` 与 `Gaussian Blur · Deep Glow`，不能让每行变成详情卡片。

### 3.3 选择与执行

- 左键单击：仅选中结果并高亮，不执行、不关闭浮层。
- 左键双击：执行该结果的默认动作，并按资源类型决定是否关闭浮层。
- 上下方向键：移动选中项；选中项始终可见。
- `Enter`：执行当前选中项，行为与双击一致。
- `Esc`：关闭浮层。

默认动作：

| 结果类型 | 双击 / Enter 默认动作 |
| --- | --- |
| NYAWORKS 简单工具 | 直接使用或执行 |
| NYAWORKS 参数工具 | 切换 Banner 到该工具面板 |
| 脚本 | 调用受控 AE 宿主桥接执行脚本 |
| 预设 | 应用到当前选中的图层 |
| 效果 | 添加到当前选中的图层 |
| 表达式 | 第一阶段打开或定位资源；不实现复杂编辑器 |

预设或效果没有选中图层时，保留搜索上下文并显示简短提示“请先选择一个图层”，不得打开多余确认流程。脚本、效果或预设不可用时，执行失败必须有明确反馈；不能静默无响应。

### 3.4 搜索匹配与排序

搜索字段包括名称、内置别名、资源文件名和必要的分类关键词。排序固定为：

1. 名称完全匹配；
2. 名称开头匹配；
3. 中文或英文别名匹配；
4. 名称包含匹配；
5. 说明、分类或路径关键词匹配。

同一资源只能在一个最合适的分组中出现，避免内置工具和资源索引重复堆叠。

搜索状态：

- 空输入：显示最近使用或常用的少量工具；
- 有匹配：显示分组结果；
- 无匹配：显示简短的“没有找到相关内容”；
- AE 未连接：内置工具和缓存资源仍可显示，依赖当前 AE 的效果结果需标记为不可执行并在执行时提示。

## 4. 搜索数据模型与数据流

### 4.1 统一搜索条目

搜索层不直接依赖各个页面的 JSX 数据，而使用统一的内部条目模型。建议字段：

```ts
type GlobalSearchItemKind = "tool" | "script" | "preset" | "effect" | "expression";

interface GlobalSearchItem {
  id: string;
  kind: GlobalSearchItemKind;
  name: string;
  aliases: string[];
  searchableText: string;
  icon: string;
  action: "execute-tool" | "run-script" | "apply-preset" | "add-effect" | "open-expression";
  sourceId?: string;
  resourceId?: string;
  requiresHost: boolean;
  opensBanner?: boolean;
}
```

现有 `HOME_TOOL_CATALOG`、资源索引和 AE 效果桥接结果分别负责提供条目；搜索排序和分组只实现一份，不能在 `HomePage.tsx` 里再写第二套资源过滤逻辑。

### 4.2 数据刷新

- 内置工具目录随应用加载；
- 本地脚本、预设和表达式使用资源 Provider 的缓存索引；
- 当前 AE 效果在宿主连接后加载，并提供手动刷新入口；
- 资源来源刷新后，搜索索引自动重建；
- 搜索输入变化只过滤内存中的统一条目，不触发磁盘全量扫描或 AE 重复查询。

## 5. Banner 工具工作区

### 5.1 默认 Banner

默认显示现有品牌 Banner 文案和背景图。默认状态不显示工具参数、工具列表或额外状态文字。

Banner 是否显示由现有首页设置中的 `homeBannerEnabled` 决定；关闭设置后，搜索和下方九宫格仍正常工作。

### 5.2 右键选择工具

在 Banner 区域右键打开紧凑菜单。菜单主要显示：

- `默认`；
- NYAWORKS 内置工具；
- 最近使用工具；
- 用户收藏工具。

右键菜单不直接塞入所有脚本、预设和 AE 效果；这些资源通过全局搜索进入 Banner 或直接执行。当前选择项显示勾选状态，点击菜单项后立即替换 Banner 内容。

### 5.3 工具 Banner

工具 Banner 是一个固定尺寸、低密度的轻量面板，只显示当前工具最常用的操作。示例：

- 图层对齐：显示对齐目标和六个对齐操作；
- 锚点设置：显示九宫格锚点操作；
- 创建合成：显示尺寸、帧率、时长和创建按钮。

工具面板不复制下面九宫格的完整功能，也不把复杂设置全部塞入 Banner。复杂工具只显示核心入口，必要时再打开完整功能页或弹窗。

### 5.4 返回默认

工具 Banner 状态显示一个紧凑的“返回默认 Banner”图标按钮，Tooltip 明确说明动作。点击后：

- 清除当前 Banner 工具；
- 恢复品牌 Banner；
- 保留下方九宫格的布局、模式和编辑状态不变。

当前右下角向下箭头不再承担未定义的轮播功能：

- 默认 Banner 下隐藏；
- 工具 Banner 下可作为返回默认的视觉入口，但必须使用明确的返回语义和 Tooltip；
- 没有实际功能时不得保留装饰性箭头。

当前左下角两个横条不作为虚假的 Banner 分页：

- 默认状态隐藏；
- 工具面板没有多页状态时隐藏；
- 只有某个工具确实拥有多个内部步骤时，才可复用为真实进度指示器。

### 5.5 Banner 与搜索联动

搜索结果执行规则：

- 简单工具双击后直接执行；
- 需要参数的工具双击后切换 Banner 到该工具；
- 脚本双击后直接运行；
- 预设和效果双击后直接应用到当前选中图层；
- 复杂工具可以由其条目声明 `opensBanner: true`，不额外显示第二个按钮。

Banner 切换不影响下方九宫格，也不创建或复制首页布局。

## 6. 视觉与动效要求

- 复用现有极夜青主题 token、边框、圆角、图标和密度规则；
- 搜索浮层与 Banner 不增加厚重嵌套卡片；
- 搜索浮层打开/关闭使用 150–220ms 的透明度和轻微位移动画；
- Banner 默认与工具面板切换使用 180–260ms 的内容淡入/淡出，不改变首页整体布局高度；
- 工具切换期间保持 Banner 容器尺寸稳定，避免下方九宫格跳动；
- 尊重 `prefers-reduced-motion` 和应用动效设置；
- 所有图标按钮具有键盘焦点样式和 Tooltip；
- 中文、英文及其他已有语言文案必须进入 `src/i18n/`，不得在组件中硬编码。

## 7. 错误与边界

- AE 未连接：内置工具仍可用；效果、脚本、预设执行时给出宿主不可用提示；
- 当前没有选中图层：预设和效果不执行，只提示选择图层；
- 资源路径失效：搜索结果可保留缓存名称，但执行时给出来源失效提示；
- 同名条目：只在名称后增加最短来源后缀；
- 空搜索索引：显示空状态，不显示伪造的资源数据；
- 搜索结果过多：浮层内部滚动，禁止撑开首页；
- 快速连续双击：动作需要串行化或去重，避免同一脚本/预设重复执行。

## 8. 工程落点

预期新增或调整的职责边界：

- `src/search/`：统一条目类型、索引合并、匹配排序和执行分发；
- `src/host/`：补充当前 AE 效果枚举、脚本执行、预设应用和效果添加的受控桥接；
- `src/components/`：搜索浮层、结果行、Banner 右键菜单和工具 Banner 容器；
- `src/pages/HomePage.tsx`：只负责首页布局和把搜索/Banner 连接到现有工具目录，不承载资源扫描逻辑；
- `src/homeLayouts/`：继续维护下方九宫格和工具组，不被 Banner 状态污染；
- `src/i18n/`：补齐搜索、Banner、错误提示和 Tooltip 的五语言文案；
- `tests/`：覆盖搜索排序/分组、双击执行、键盘操作、Banner 右键切换、恢复默认和边界状态。

如果现有宿主桥接暂不支持某一类真实 AE 动作，第一阶段可以先完成浏览器可验证的 fixture 分发和明确的未连接提示，但不得声称已经完成真实 AE 执行验收。

## 9. 验收标准

### 全局搜索

- 搜索框支持鼠标聚焦和 `Ctrl + K / ⌘ K`；
- 结果浮层不改变首页整体布局；
- 每条结果默认只显示图标和名称；
- 单击只选中，双击或 Enter 执行；
- 内置工具、本地资源和当前 AE 效果可以进入统一结果；
- 中文、英文名称和别名可以匹配；
- 无结果、AE 未连接、无选中图层和失效来源都有明确反馈。

### Banner

- 默认显示品牌 Banner；
- Banner 右键可以选择内置工具；
- 选择工具后 Banner 替换为对应轻量工具面板；
- Banner 不出现第二套九宫格；
- 下方九宫格布局和交互不受影响；
- 工具 Banner 可恢复默认 Banner；
- 没有实际功能时不显示左下分页条和右下箭头；
- 工具 Banner 切换不造成首页闪烁或整体跳动。

### 验证边界

- `npm.cmd run typecheck`、`npm.cmd run test`、`npm.cmd run build` 和 `npm.cmd run verify` 证明静态与浏览器工程检查；
- 浏览器 fixture 只能证明搜索和 Banner UI 的渲染与状态流；
- 真实脚本执行、预设应用、效果添加和当前 AE 版本发现必须在实际 CEP/AE 宿主中单独记录版本、路径和结果。
