# NYAWORKS 新建图层九宫格开发规格

日期：2026-10-04
状态：第一版已实现，待真实 AE 验收
范围：新建图层九宫格、通用图层 Action、摄像机控制器、预合成与解预合成

## 1. 设计目标

新建图层九宫格不是一组互相独立的按钮，而是 NYAWORKS 统一 Action Platform 的一个快捷入口。所有会改变 AE 工程状态的逻辑必须集中在 Host Action 中，九宫格、首页、合成功能页、全局搜索、Command Palette 和 Nya Pie 只复用相同的 Action ID。

本阶段目标：

- 提供符合 AE 使用习惯的九个图层/合成操作；
- 统一处理无选中、单选和多选图层的插入位置与时间范围；
- 保留 AE 原生语义，同时增加必要的可编辑控制参数；
- 通过 Alt / Ctrl / Shift + 左键提供可发现、可解释的扩展操作；
- 让预合成与解预合成可以脱离九宫格，在其他页面独立使用；
- 支持中文 AE / English AE，避免把界面显示名称作为核心判断依据。

## 2. 九宫格最终布局

九个位置固定为：

```text
文本      纯色      形状
调整层    空对象    摄像机
灯光      预合成    解预合成
```

图标继续使用项目现有 Phosphor Icons 风格，统一尺寸、描边粗细、悬停和选中状态。

建议语义：

- 文本：`TextT`
- 纯色：实心矩形
- 形状：圆角矩形或几何形状
- 调整层：滑杆或调整图标
- 空对象：中心控制点 / Null 语义图标
- 摄像机：摄像机
- 灯光：灯泡或聚光灯
- 预合成：堆叠合成
- 解预合成：拆分堆叠或展开合成

“3D 控制器”不再占用九宫格位置。它是摄像机 Action 自动创建的辅助层，也可以作为空对象的 Shift 扩展模式。

## 3. 统一创建基线

所有创建型 Action 先读取并规范化当前 AE 上下文：

```ts
interface LayerCreationContext {
  activeComp: CompItem;
  selectedLayers: Layer[];
  selectionMode: "none" | "single" | "multiple";
  compStart: number;
  compEnd: number;
  insertBeforeIndex: number;
  rangeStart: number;
  rangeEnd: number;
}
```

### 3.1 无选中图层

- 新建到图层堆栈最上方；
- 入点为合成实际起始时间 `displayStartTime`；
- 出点为 `displayStartTime + duration`；
- 新建层成为当前选中目标；
- 没有活动合成时不执行并返回可解释错误。

### 3.2 单选图层

- 新建层插入到选中图层上方；
- 入点、出点匹配选中图层；
- 新建层成为当前选中目标；
- 需要建立父子关系的 Action 必须保持被控图层世界坐标不跳动。

### 3.3 多选图层

- 新建层插入到最上方选中图层的上方；
- 入点为所有选中图层最早的 `inPoint`；
- 出点为所有选中图层最晚的 `outPoint`；
- 使用一个连续时间区间；
- 默认创建一个统一控制层，而不是为每个图层重复创建。

### 3.4 共同安全规则

- Host 执行前重新检查活动合成、选中状态和必要条件；
- 所有工程修改都在一个 Undo Group 内完成；
- 不因前端 Disabled 状态而省略 Host 侧校验；
- 创建失败时不留下半成品；
- 新建结果、失败原因和影响数量通过结构化结果返回。

## 4. 九个功能规格

### 4.1 文本

普通点击创建内容为小写 `text` 的文字层。

- 不在项目中写死字体；
- 优先继承 AE 当前文字工具 / 字符面板最近使用的字体；
- 如果 AE 当前没有可继承字体，则使用 AE 默认字体；
- 不显式覆盖图层名称，保持 AE 原生“图层名跟随源文字内容”的行为；
- 自动将锚点调整到文字边界中心；
- 时间范围遵守统一基线。

实现验收必须在真实 AE 中确认：切换 AE 最近使用字体后，点击按钮创建的文字层使用该字体。

扩展：

- `Alt + 点击` 打开 NYAWORKS 文字层编辑器，不直接创建图层；
- `读取` 只接受当前合成中单个选中的文字层，并读取其源文字；
- `应用` 将编辑器内容写回已读取的目标文字层，同时保留原 TextDocument 样式；
- `创建` 始终按统一时间和插入规则创建新的点文字层；
- 编辑器主题和语言跟随 NYAWORKS 主面板，且不在 AE“窗口 > 扩展”中增加独立菜单入口；
- `Ctrl`、`Shift` 和未定义组合回退到普通点文字创建行为。

### 4.2 纯色

使用 AE 原生 Solid，不使用 Shape Layer 伪装。

- 默认颜色为黑色；
- 默认尺寸为合成尺寸；
- 默认像素比例继承合成；
- 时间范围遵守统一基线；
- 只添加 AE 原生 `Fill` 效果，用户直接在该效果的颜色参数中修改颜色；
- 默认颜色为黑色；
- 本按钮不提供修饰键扩展，所有修饰键均回退到普通创建。

### 4.3 形状

普通点击创建居中圆角矩形。

默认参数：

- 宽度：500 px；
- 高度：500 px；
- 圆角：50 px；
- 图层位置：合成中心；
- 锚点：矩形中心；
- 默认使用 Shape Layer 原生路径和填充。

效果控件提供：

```text
Nya 圆角矩形
├── Nya 宽度
├── Nya 高度
├── Nya 圆角值
├── Nya 分离圆角
├── Nya 左上圆角
├── Nya 右上圆角
├── Nya 右下圆角
└── Nya 左下圆角
```

默认关闭“分离圆角”。开启后，四个角可以分别调整。上述列表记录参数清单，不代表伪效果的最终分组布局。按用户于 2026-10-08 的要求，伪效果的参数排列与分组以其提供的玄如意效果控件截图为基准；品牌命名和内部实现保持 NYAWORKS 自有，不擅自增加分组层级。

2026-10-08 补充核对：[参考原图与交互记录](../../references/xuanruyi-rounded-rectangle-controls.md)已归档。新伪效果的宽度、高度、圆角值和分离圆角直接列在效果下；四角置于可独立展开/收起的“分离参数”组，顺序为左上、右上、右下、左下，显示单位为百分比。折叠组不控制分离开关。上述“50 px”保留为原 `v1` 候选的历史定义，不适用于下面的 `v2`。

2026-10-09 `v2` 行为修订：总圆角值采用 0–100 的相对尺度，默认 50；未分离时四角均为 `min(宽, 高) / 2 × 总圆角值 / 100`，0 为直角、正方形的 100 为圆形。分离时总圆角不参与计算，四角各自采用相同基准与自己的 0–100% 数值；默认四角均为 50%，因此新建图层首次切换不改变形状。错误的 `v1` 模板后续从扩展交付移除，已存在的 AE 工程实例和表达式不自动迁移。

形状变体：

- `Alt`：`Nya 圆`，使用半径控制；
- `Ctrl`：`Nya 三角形`，使用半径、旋转和圆角控制；
- `Shift`：`Nya 星形`，使用角数、内外半径、旋转和内外圆角控制；
- 删除三键选择菜单，避免与三个直接修饰键重复。

### 4.4 调整层

保持基础实现：

- 创建真正的 Adjustment Layer；
- 默认覆盖合成画面；
- 时间范围遵守统一基线；
- 不自动添加效果；
- 不改变原有图层属性。

### 4.5 空对象

所有新建空对象默认：

- 设置为参考线图层 `guideLayer`；
- 锚点位于空对象几何中心；
- 默认创建 2D Null；
- 名称使用 `Nya 控制`，重名时依次使用 `Nya 控制 2`、`Nya 控制 3`；
- 无选中时位置为合成中心；
- 有选中时按选择模式计算位置；
- 不参与最终渲染。

行为：

- 无选中：创建一个独立空对象；
- 单选：创建空对象并将选中图层设为子级；
- 多选：创建一个空对象统一控制所有选中图层；
- `Alt`：每个选中图层创建一个空对象；
- `Ctrl`：将控制器放在选中图层平均位置；
- `Shift`：创建 3D Null；
- 不再提供三键模式菜单。

建立父子级时优先使用保持世界坐标的方式，避免被控图层突然跳动。

### 4.6 摄像机

普通点击创建完整摄像机控制组合：

```text
Nya 摄像机控制（3D 参考线空对象）
└── Nya 摄像机
```

默认规格：

- 固定 35mm 摄像机；
- 不弹出 AE 摄像机设置窗口；
- 自动创建 3D 控制器；
- 控制器自动开启 3D；
- 控制器设置为参考线图层；
- 摄像机绑定到控制器；
- 摄像机与控制器使用相同时间范围；
- 无选中时控制器位于合成中心；
- 有选中时优先使用选中区域中心，无法可靠计算时回退到合成中心；
- 创建完成后选中控制器。
- 控制器明确排列在摄像机图层上方。

控制参数放在 `Nya 摄像机控制` 的效果控件中，不把自定义参数堆到摄像机原生属性上。

第一版控制参数：

```text
Nya 目标图层
Nya 相机位置 X / Y / Z
Nya 相机旋转 X / Y / Z
Nya 自动移动 / Nya 移动速度
Nya 镜头焦距 / Nya 镜头景深
Nya 焦点自动 / Nya 焦点距离
Nya 抖动强度 / Nya 抖动频率
```

当前实现使用 AE 原生 Expression Controls 提供中文参数。可折叠自定义参数组后续纳入[共享伪效果系统规划](2026-10-08-pseudo-effect-system-design.md)：拟通过扩展内置的 `.ffx` 控件模板与统一 Host 加载/绑定支持，不要求用户修改 AE 的 `PresetEffects.xml` 或安装制作器。该系统同时面向形状、摄像机及后续工具，现阶段仅完成规划，模板可移植性和兼容性仍待验证；本规格既有实现及旧工程不会自动迁移。

建议扩展：

- `Ctrl`：创建控制组合后打开 AE 原生摄像机设置窗口；
- 删除 `Alt + Ctrl + Shift` 扩展。

### 4.7 灯光

普通点击创建点光源，遵守统一插入和时间范围规则。

建议扩展：

- `Alt`：聚光灯；
- `Ctrl`：平行光；
- `Shift`：环境光。

创建后显式设置 Position 与 Point of Interest，使灯光位于合成视觉中心；颜色和强度使用 AE 默认值，不在普通点击时打开设置窗口。

### 4.8 预合成

预合成是通用 Action，不是九宫格专属逻辑。

普通点击：

- 必须有一个或多个选中图层；
- 没有选中图层时不可执行；
- 默认使用普通预合成；
- 执行完成后选中新预合成层；
- 使用一个 Undo Group。
- 新合成时长匹配选中图层最早入点到最晚出点，内部图层时间归零；

该 Action 由九宫格先行接入，并保持可被以下入口复用：

```text
九宫格（本阶段）
合成功能页（后续入口）
首页独立快捷入口（后续入口）
全局搜索
Command Palette
Nya Pie
```

扩展：

- `Alt`：移动全部属性，并按选中图层的视觉边界裁切新合成尺寸；
- 删除与普通点击重复的 `Ctrl` 变体；
- `Alt + Ctrl + Shift`：创建后打开新预合成的 AE 原生合成设置窗口。

### 4.9 解预合成

解预合成同样是通用 Action。本阶段先接入九宫格，后续合成功能页和首页独立入口直接复用相同 Action ID。

第一版只处理单层、单级解预合成：

- 必须选中一个预合成图层；
- 普通图层不可执行；
- 将内部图层提取到当前合成；
- 保留图层顺序、时间范围、变换、关键帧、效果、遮罩和标签；
- 成功后删除原预合成层；
- 提取出的图层自动成为选中状态；
- 全部操作使用一个 Undo Group；
- 失败时不得留下部分提取结果。

第一版不承诺：

- 递归解开嵌套预合成；
- 多个预合成同时解开；
- 复杂表达式路径自动改写；
- 复杂轨道遮罩、3D 摄像机和 Collapse Transformations 的完全重构。

该 Action 必须明确报告无法安全转换的情况，而不是静默生成错误工程。

## 5. 修饰键与 Tooltip 规范

修饰键统一采用以下语义：

- 普通点击：默认操作；
- `Alt`：同类型替代模式；
- `Ctrl`：改变作用范围或目标方式；
- `Shift`：3D 或高级模式；
- `Alt + Ctrl + Shift`：仅在预合成按钮上作为“合成设置”直接操作。

并非每个按钮都必须实现所有修饰键。没有安全、清晰用途的组合不显示为伪功能。

Tooltip 必须说明当前按钮真实支持的操作，例如：

```text
形状
点击：圆角矩形
Alt：圆形
Ctrl：三角形
Shift：星形
```

窄面板只保留图标，Tooltip 仍显示完整说明。

## 6. Action 与 Host 架构

目标调用链：

```text
九宫格 / 首页 / 合成页 / 搜索 / Nya Pie
→ Action ID
→ Action Runner
→ Action Registry
→ Host Executor
→ CEP Bridge
→ ExtendScript / AE Host
```

建议 Action ID：

```text
layer.createText
layer.createSolid
layer.createShape
layer.createAdjustment
layer.createNull
layer.createCameraRig
layer.createLight
layer.precomposeSelected
layer.unprecomposeSelected
```

创建型 Action 的输入至少包含：

```ts
interface LayerActionPayload {
  actionId: string;
  modifier: "none" | "alt" | "ctrl" | "shift" | "settings";
  source: "layer-grid" | "home" | "composition" | "search" | "nya-pie";
}
```

多键组合默认回退普通点击，避免误触某个单键变体。只有预合成把 `Alt + Ctrl + Shift` 映射为稳定的 `settings` modifier，并由 Host 打开新预合成的原生合成设置窗口。

React 只负责 UI、修饰键识别、Action 调度和结果展示。AE DOM、时间范围、图层插入、父子关系、效果控件和 Undo Group 全部放在 Host 层。

预合成和解预合成不得在九宫格、首页和合成功能页各维护一套实现。

## 7. 错误与状态反馈

统一错误至少覆盖：

```text
host-unavailable
no-active-comp
no-selected-layer
invalid-selection
unsupported-layer-type
precompose-required
unprecompose-required
unsupported-nested-precomp
host-error
```

反馈要求：

- 成功反馈包含功能名称；
- 预合成、解预合成反馈包含处理数量；
- 失败反馈说明用户可以如何处理；
- 执行失败不能改变原选中状态；
- 所有 Host 错误转换为结构化结果，不直接把 ExtendScript 堆栈展示给用户。

## 8. 兼容性与安全

- 目标环境：After Effects 2022–2026+；
- 首要验证平台：Windows；
- 同时考虑 macOS 路径与文件编码；
- 中文 AE / English AE 均不能依赖显示名称判断；
- 效果、属性和图层类型优先使用稳定 API、Match Name 或索引；
- 所有工程修改必须支持 AE Undo；
- 解预合成必须在操作前收集必要上下文，避免中途失败后破坏工程；
- 不允许前端直接传入任意 ExtendScript 代码；
- Action 参数必须经过 Host 侧校验。

## 9. 验收矩阵

每个创建型 Action 至少验收：

| 场景 | 要求 |
|---|---|
| 无选中图层 | 最上方、完整合成时间范围 |
| 单选图层 | 插入上方、匹配单层时间范围 |
| 多选图层 | 插入最上方选中层上方、匹配整体时间范围 |
| 锁定图层 | 不破坏锁定状态，错误可解释 |
| 父子级 | 世界坐标不异常跳动 |
| 2D / 3D | 空对象和摄像机按规格切换 |
| 中文 AE | 可创建、可执行、参数可见 |
| English AE | 可创建、可执行、参数可见 |
| Undo | 一次操作可以完整撤销 |
| 重复执行 | 不产生半成品或重复绑定 |

额外验收：

- 文字层继承 AE 最近使用字体；
- 纯色层为黑色 Solid，并拥有 Fill 效果；
- 形状层居中，锚点在中心，圆角参数可调；
- 所有空对象默认是参考线图层；
- 摄像机控制器为 3D 参考线图层，并能控制摄像机；
- 预合成、解预合成通过稳定 Action ID 从九宫格执行，并可被后续首页独立入口和合成功能页直接复用；
- 解预合成失败时不产生部分结果。

## 10. 实施阶段

正式开发按以下可验证增量推进：

1. 建立统一图层创建上下文和时间 / 插入基线；
2. 实现文本、纯色、形状、调整层；
3. 实现空对象和父子级逻辑；
4. 实现摄像机控制器和参数效果控件；
5. 实现灯光；
6. 抽取预合成 / 解预合成为通用 Action；
7. 接入九宫格，并为后续首页独立入口和合成功能页保留统一 Action 接口；
8. 接入修饰键、Tooltip、错误反馈；
9. 执行 TypeScript、测试、构建和 CEP 检查；
10. 在真实 AE 中完成最终验收。

本规格不包含具体代码实现，不允许在规格审阅完成前直接开始大规模编码。
