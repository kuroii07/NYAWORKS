# 摄像机控制器参数审阅稿（未确认，暂不实施）

日期：2026-10-12。基线：`3ed8415`。目的：将已有的 15 项摄像机控制参数整理为一份可折叠伪效果规格，同时保持当前摄像机与 3D guide 控制器的创建流程。用户先确认控件、默认值、范围及联动，再制定实施步骤和修改摄像机代码。以下“建议”尚未进入产品；不要将其误写为当前 AE 实测行为。

## 当前实现与不变边界

普通点击创建 35mm 摄像机及位于其上方的 3D guide 控制器；控制器默认位置取所选图层可读取位置的算术平均，无有效选层时为 `[合成宽/2, 合成高/2, 0]`。摄像机局部位置 `[0, 0, -1000]`，控制器被选中。Ctrl 创建后打开 AE 原生摄像机设置。已有图层、表达式、中文控件及旧工程不自动迁移或重命名；五语言摄像机/控制器**图层名**已经本地化，15 个效果控件目前仍为中文原生 Expression Controls。原生控件当前没有本产品定义的统一拖动/输入上下限。

现有联动：位置 X/Y/Z 设置控制器 3D Position；自动移动打开后额外沿 Z 轴加 `time × 移动速度`；抖动强度大于 0 时附加 `wiggle(频率, 强度)` 偏移，两个输入在表达式中取非负。三轴旋转分别驱动控制器旋转。镜头焦距令 Camera Zoom=`合成宽度 × 焦距 / 36`；景深开关驱动摄像机景深。目标图层选定后驱动 Point of Interest；开启焦点自动且目标有效时，焦点距离取摄像机到目标锚点的世界空间距离，否则用手动焦点距离。目标层初始为空，未自动绑定当前选层。已有计算公式仅作为兼容基线记录，不代表所有 AE/语言组合已实机验收。

## 建议的 6 组、15 项参数

范围分别指伪效果滑块**拖动显示范围**与**允许键入范围**；它们是待确认的产品建议。单位为当前业务表达式所使用的合成/世界坐标单位，mm 仅用于镜头焦距。`±` 表示正负对称。角度保留原生 Angle 的负值和多圈，不人为规定输入上限。复选框为 0/1。

| 组 | 稳定语义 ID | 当前中文控件 | 类型/单位 | 当前默认 | 建议拖动 / 键入范围 | 作用与联动 |
| --- | --- | --- | --- | --- | --- | --- |
| 目标 | `target.layer` | Nya 目标图层 | Layer | 无目标（0） | 仅合成内图层或无目标 | 选目标后驱动摄像机目标点；自动对焦开启时才参与焦距计算 |
| 位置与旋转 | `position.x` | Nya 相机位置 X | Slider / 坐标单位 | 创建时控制器 X | ±10000 / ±100000 | 控制器 3D Position X |
| 位置与旋转 | `position.y` | Nya 相机位置 Y | Slider / 坐标单位 | 创建时控制器 Y | ±10000 / ±100000 | 控制器 3D Position Y |
| 位置与旋转 | `position.z` | Nya 相机位置 Z | Slider / 坐标单位 | 创建时控制器 Z | ±20000 / ±100000 | 控制器 3D Position Z；与自动移动相加 |
| 位置与旋转 | `rotation.x` | Nya 相机旋转 X | Angle / ° | 0 | 原生角度，无额外限幅 | 控制器 X Rotation |
| 位置与旋转 | `rotation.y` | Nya 相机旋转 Y | Angle / ° | 0 | 同上 | 控制器 Y Rotation |
| 位置与旋转 | `rotation.z` | Nya 相机旋转 Z | Angle / ° | 0 | 同上 | 控制器 Z Rotation |
| 自动移动 | `motion.enabled` | Nya 自动移动 | Checkbox | 关（0） | 关/开 | 关闭时速度保留但不生效 |
| 自动移动 | `motion.speed` | Nya 移动速度 | Slider / 坐标单位/秒 | 0 | ±2000 / ±10000 | 正值沿 +Z，负值沿 -Z；建议首版保留当前 `time × speed` 公式 |
| 镜头 | `lens.focalLength` | Nya 镜头焦距 | Slider / mm | 35 | 1–200 / 1–1000 | 通过原有换算驱动 Camera Zoom；新建初始仍为 35mm |

| 对焦 | `focus.distance` | Nya 焦点距离 | Slider / 世界空间距离 | 1000 | 1–10000 / 1–100000 | 作为手动值或无目标时回退值 |
| 抖动 | `shake.strength` | Nya 抖动强度 | Slider / 坐标单位 | 0 | 0–300 / 0–5000 | 0 时不抖；作用于控制器位置，频率值仍保留 |
| 抖动 | `shake.frequency` | Nya 抖动频率 | Slider / 次/秒 | 2 | 0–20 / 0–100 | 与强度共同决定 wiggle；建议 0 频率时不产生运动 |

建议仅在**新建实例**时初始化三个位置参数为本次控制器位置；不要把合成中心写死在 `.ffx` 静态默认中。用户输入在允许范围内不做隐藏裁剪；如果制作工具不能同时表达拖动范围和键入范围，先拿实际导出模板验证，再调整规格，不把模板限制凭空当成 AE 保证。控件允许关键帧；类型、真实索引与表达式绑定以保存后重新加载的 `.ffx` 实测为准。未来表达式输入超范围时的行为需要另行验证，不能仅凭 UI 限制保证安全。

## 待确认的交互与实施门槛

1. 确认仍保留全部 15 项、上表默认值、六组结构和范围。拖动与键入范围不同会影响模板制作；对 1mm–1000mm 镜头焦距等偏极端输入，如需收紧请明确。
2. 建议维持现有 `time × speed` 以避免同时改变移动时基；非 0 起始时间会造成打开自动移动时的位置跃迁。若改用从控制器入点起算，属于单独行为变更，需先决定并测试非 0 合成起始时间。
3. 建议目标层为空时仍可创建，自动对焦回退到 1000 的手动值；目标层删除、跨合成复制、控制器重命名和多组摄像机并存要有明确的安全绑定及回归测试，不凭控制层显示名称猜测身份。
4. 参数审阅通过后再写实施计划：只为摄像机新建伪效果模板/规格/Catalog 映射和 Host 绑定；创建前校验资产，出错移除本次创建的摄像机与控制器并恢复选择。保护四种形状 FFX、schema、Catalog 旧条目、原有 Null 与调整层行为；五语言对照和既有控件回归均应作为门槛。
5. 在独立 AE 测试工程核查默认、极值、逐项联动、关键帧、复制、重命名、Undo/Redo、保存重开、Ctrl 设置窗口，以及中文/英文 AE 宿主与五种面板语言。静态/Mock/构建通过不能替代真实宿主验收。
