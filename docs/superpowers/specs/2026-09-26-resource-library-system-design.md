# NYAWORKS 资源系统设计

日期：2026-09-26
状态：已确认，待实现规划

## 1. 目标

将“资源”设计为 NYAWORKS 的独立功能系统，而不是设置页中的若干目录输入框。

系统由两个明确分工的界面组成：

```text
当前打开的 AE 默认目录 + 用户手动添加的目录
                    ↓
              资源索引与资源状态
                    ↓
设置页「资源」              左侧功能页「资源」
来源、扫描和规则            搜索、浏览、预览和使用
```

第一阶段优先完成本地资源库；云端资源库保留为后续能力，但不得以可使用的空页面或虚假下载入口出现。

## 2. 已确认的产品边界

### 2.1 左侧功能页

左侧主导航新增“资源”，位置固定在“媒体”下方：

```text
效果 → 媒体 → 资源
```

“媒体”继续承载图片、视频、音频等素材方向；“资源”承载可调用的 AE 脚本、面板、预设、表达式及未来云端工具包。两者不得合并为同一功能页。

### 2.2 设置页

设置页保留“资源”分类，但它只管理资源的来源、扫描、使用规则和资源配置数据。它不承担资源浏览或执行。

当前独立的“关于”页、常规页的全局重置和更新能力不迁入资源设置页，避免与参考图中的“数据与备份 / 关于”区域重复。

### 2.3 AE 版本规则

- NYAWORKS 只自动读取**当前打开面板的 AE 宿主版本**的默认资源目录。
- 例如在 AE 2025 中打开面板，只自动接入 AE 2025 的系统脚本、面板、启动脚本和预设目录。
- 不扫描、不探测、不自动合并其他 AE 版本。
- 用户若要使用其他版本的目录，必须自己作为自定义来源添加；其在系统中就是普通自定义来源，不额外承诺跨版本兼容。
- 当前 AE 的路径由 CEP 宿主运行时识别，禁止把某个 Windows 安装路径硬编码进前端或默认配置。

## 3. 资源类型与来源

### 3.1 当前 AE 内置来源

由当前宿主自动产生以下只读来源：

- `Scripts`：脚本文件。
- `ScriptUI Panels`：可停靠面板来源。
- `Startup`：启动脚本来源。
- `Presets`：AE 预设来源。

内置来源不可删除或改路径，但用户可在索引中停用某一来源、重新识别当前宿主路径或重新扫描。每项展示宿主版本、路径摘要、可用状态、索引数量和上次扫描时间。

### 3.2 自定义来源

用户添加来源时先选择资源类型，再选择目录并输入可识别名称：

- 脚本库：`.jsx`、`.jsxbin`、`.js`。
- 预设库：`.ffx`。
- 表达式库：第一版支持项目定义的表达式文件或片段格式。

自定义来源支持改名、改路径、启用/停用、重新扫描、在系统中打开和移除。来源路径失效时保留来源记录与最后一次索引摘要，但明确标为失效，不能静默删除用户资料。

## 4. 资源设置页

页面在当前 NYAWORKS 520px 面板宽度下采用纵向分区，不能复刻参考图中“名称、长路径、状态和多个图标按钮”硬塞同一行的布局。

### 4.1 资源来源

顶部区分两组：

1. **当前 AE 内置来源**：紧凑状态行，包含类型、当前 AE 版本、路径摘要、数量、扫描状态和更多菜单。
2. **我的资源来源**：可编辑来源列表；右上角“添加来源”打开 NYAWORKS 自定义弹窗，完成类型、名称与目录选择。

行项目点击后在本行下方展开详情，避免为每个来源常驻大量按钮。文件夹、更多、重扫等纯图标按钮必须有 Tooltip。

### 4.2 扫描与索引

- 主操作为“更新资源索引”，而不是每次扩展启动时全量扫描。
- 首次进入资源功能页优先展示上次成功索引的缓存；新增、修改路径和用户主动刷新时，才扫描受影响来源。
- 扫描进行中显示当前来源、已发现数量和可取消状态。
- 完成反馈必须可理解：新增、更新、跳过无效文件、失效路径、同名冲突的数量。
- 失败保留旧索引，不清空可用资源；仅更新来源状态与错误摘要。

### 4.3 使用规则与安全

- 同名资源默认策略为“执行前询问”；后续可切换为优先特定来源或跳过。
- 外部脚本默认首次运行确认；“可信脚本”管理页可查看来源、撤销授权和重新要求确认。
- ScriptUI Panels 与 Startup 资源不能伪装成普通脚本直接执行：前者明确显示需重启 AE 后加载，后者只显示启动加载状态与来源。
- 资源配置导入/导出只包含来源、分类、收藏、索引配置和用户元数据；不包含 API Key，也不复制、覆盖或删除用户原始资源文件。
- “添加到首页”绝不自动进行。未来仅能从资源详情由用户明确添加，且必须接入首页布局的既有编辑规则。

## 5. 左侧资源功能页

资源功能页是用户实际查找和使用资源的地方，第一阶段只显示本地资源。

### 5.1 信息架构

顶部区域：

- 全局资源搜索。
- 资源类型筛选：全部、脚本、面板、启动脚本、预设、表达式。
- 当前来源/分类入口。
- 当前索引状态与刷新入口。

内容区域同时保留“目录定位”和“内容浏览”两种能力：

- 来源与分类以可折叠目录树、来源选择器或面包屑呈现；默认 520px 宽度不固定占据一列，避免压缩资源内容。
- 结果按“当前 AE 内置资源”和“我的资源”分组；搜索状态下仍保留来源标记。
- 用户可进入分类，例如“效果预设 / 扭曲”或“我的脚本 / 合成工具”，并通过面包屑返回。

### 5.2 列表与卡片

资源展示遵循内容能力，而不是强制所有文件使用同一种网格：

- 脚本、ScriptUI Panels、Startup：默认紧凑列表，强调名称、来源、状态和动作。
- 预设、表达式与未来模板：有可靠封面或预览时使用三列资源卡网格。
- 没有预览的资源使用清晰的类型卡或列表项，不伪造通用“AE”效果封面。
- 资源卡/资源行统一显示类型图标、名称、来源、收藏状态；详情包含完整路径、标签、最近使用和可用操作。

右键或更多菜单至少提供：

- 运行或应用。
- 收藏/取消收藏。
- 在系统中显示。
- 复制路径。
- 编辑来源。
- 从索引移除（只移除索引记录，不删除原文件）。

### 5.3 类型动作

- 脚本：在确认安全规则后运行。
- ScriptUI Panels：显示面板来源和重启加载说明。
- Startup：显示来源和启动状态，不提供假冒的立即运行。
- 预设：应用于当前选中图层；没有有效目标时明确解释原因。
- 表达式：插入当前选中的可表达式属性；没有有效属性时明确解释原因。

尚未完成 CEP 宿主操作前，对应按钮必须是明确的计划态或不可用态，不能以成功状态伪装。

## 6. 动态预览策略

### 6.1 统一预览契约

本地资源和未来云端资源共用资源卡与预览组件。完整预览资源包含：

```text
cover.webp / cover.png     静态首帧
preview.webm / preview.mp4 2–4 秒静音循环动画
manifest.json              标题、分类、版本、预览信息
```

资源卡优先显示静态封面，仅在悬停、键盘聚焦或点选当前卡片时加载并播放循环动画；离开时暂停或回到首帧。绝不让当前视口中所有卡片同时播放。

### 6.2 云端资源库

云端资源由资源作者或云端发布流程提供正式封面和循环预览媒体。云端库后续需要独立解决目录、下载、安装、版本、缓存、授权、离线状态、网络安全与资源签名；本设计不把这些能力伪装为第一阶段已有功能。

### 6.3 本地资源预览

`.ffx` 等本地资源通常不包含可直接读取的视觉缩略图。预览生成策略为：

1. 若资源旁有同名封面文件，优先使用。
2. 若无封面，用户可按需发起“生成动态预览”。
3. 用户选择或确认预览模板，例如文字动画、图形动画、调色效果、通用合成。
4. 与当前 AE 版本匹配的独立临时渲染任务在标准测试合成中应用资源，输出短循环媒体和首帧封面。
5. 预览按“资源路径、文件修改信息、模板 ID、AE 版本、渲染器版本”建立缓存键；资源未变化时不重新渲染。

预览生成不得直接在用户正在编辑的工程内创建测试合成，避免污染工程内容与撤销历史。第三方插件缺失、资源依赖特定素材或渲染失败时，保留静态类型卡并显示可理解的失败原因。

首期不在扫描阶段批量渲染全部资源。动态预览是用户按需生成的后续增量；云端资源可直接使用作者提供的预览。

### 6.4 真实 CEP 兼容性

生产环境需要验证目标 AE CEP Chromium 对视频格式与本地缓存媒体 URL 的实际支持。开发浏览器中的视频可播放，不等于 AE CEP 中可播放。

预览组件必须有静态封面回退；编码格式、缓存媒体 URL 解析及任何必要的受控宿主桥接，在真实目标 AE 版本中验收后才能定稿。

## 7. 数据与模块边界

资源系统保持独立，不混入通用设置、首页布局或 AI 设置。建议拆分为：

```text
src/resources/
  types.ts                 资源、来源、索引与预览元数据
  resourceStorage.ts       版本化非敏感配置与缓存索引
  sourceOperations.ts      添加、编辑、停用、移除来源
  indexOperations.ts       扫描结果归一化、冲突与失效处理
  resourceActions.ts       类型动作的前端入口与可用性判断
  previewMetadata.ts       封面、循环预览与缓存键
  ResourceProvider.tsx     资源状态边界
src/pages/
  ResourcesPage.tsx        左侧资源功能页
  ResourceSettingsPanel.tsx 设置页资源分类
src/host/
  resourceBridge.ts        受控 CEP/ExtendScript 宿主适配层
```

React 组件不得直接读取文件系统或执行 AE 脚本。目录发现、扫描、文件动作、临时渲染与本地媒体解析必须通过受控 CEP/ExtendScript 桥接；浏览器开发环境使用明确的开发适配器，不伪装为真实宿主能力。

资源实体至少包含：

```ts
interface ResourceSource {
  id: string;
  kind: "ae-default" | "custom";
  resourceType: "script" | "panel" | "startup" | "preset" | "expression";
  name: string;
  path: string;
  enabled: boolean;
  hostVersion: string | null;
  lastScannedAt: string | null;
  status: "ready" | "scanning" | "missing" | "error";
}

interface IndexedResource {
  id: string;
  sourceId: string;
  resourceType: ResourceSource["resourceType"];
  name: string;
  relativePath: string;
  modifiedAt: string | null;
  favorite: boolean;
  lastUsedAt: string | null;
  preview: {
    coverUri: string | null;
    loopUri: string | null;
    cacheKey: string | null;
    status: "none" | "ready" | "rendering" | "failed";
  };
}
```

路径、资源索引和用户元数据的持久化需要版本号与归一化逻辑；资源文件本身始终保留在原位置。

## 8. 视觉、可访问性与国际化

- 延续 NYAWORKS 五套暗色主题、线性图标、青色主强调、轻量描边、圆角和紧凑密度。
- 资源功能页不复制参考产品的纯黑密集手风琴界面，也不将每一项包成厚重卡片。
- 青色只表达当前选中、扫描进度或主操作；失效和危险操作使用受限警示色。
- 默认 520px 面板宽度下无横向滚动；目录树在狭窄空间改为可收起层或来源选择器。
- 所有图标按钮有 Tooltip 和 aria 标签；右键操作有键盘可达的更多菜单替代。
- 动态预览遵从通用设置中的“标准 / 减少 / 关闭”动效偏好；减少或关闭时只显示静态封面。
- 新增文案必须覆盖简体中文、繁體中文、English、日本語、한국어，并验证长文本、空状态、失效状态和扫描状态。

## 9. 分阶段交付

### 第一阶段：本地资源库基础

- 当前 AE 默认来源识别。
- 自定义脚本、预设、表达式来源管理。
- 资源设置页、索引、缓存、扫描状态与冲突提示。
- 左侧资源页的目录定位、搜索、分组、列表/静态资源卡、收藏与来源操作。
- 清晰的不可用态与浏览器/CEP 开发适配边界。

### 第二阶段：真实 AE 动作与本地预览

- 脚本运行、预设应用、表达式插入等已验证的宿主动作。
- ScriptUI Panels 与 Startup 的真实状态识别。
- 资源专用的可信脚本授权。
- 同名资源处理策略。
- 用户按需生成本地静态/动态预览及缓存管理。

### 第三阶段：云端资源库

- 云端目录树、分类、搜索、资源详情和作者提供的预览媒体。
- 下载、安装、更新、缓存、离线状态、授权和资源签名。
- 与本地资源统一的收藏、最近使用和资源卡体验。

## 10. 验收标准

- 打开不同版本的 AE 时，只自动展示当前宿主版本的默认资源来源。
- 其他 AE 版本绝不被自动扫描；用户可作为自定义目录手动添加。
- 用户能添加、编辑、停用、刷新和移除自定义来源，且不会删除原始文件。
- 索引失败不会清空旧结果；失效来源和冲突能清楚说明。
- 左侧“资源”位于“媒体”下方，设置“资源”页与功能“资源”页职责不重复。
- 本地资源支持搜索、类型/来源定位、收藏、路径查看和键盘可达的更多操作。
- 未接入的宿主动作、动态预览与云端资源均明确标明阶段状态，不伪装可用。
- 有预览的资源可使用资源卡，无预览资源保持类型卡或列表，不使用伪造效果图。
- 本地动态预览不会污染当前用户工程，并有静态封面回退。
- 五语言、五主题和三种界面密度下无横向溢出；动效偏好能影响动态预览播放。
- 自动化测试、类型检查、生产构建和 `dist` 冒烟检查与真实 AE CEP 宿主验收分别记录，不混为同一结论。
