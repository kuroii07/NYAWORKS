# NYAWORKS AI 设置系统设计

日期：2026-09-24
状态：待用户审阅

## 1. 目标

把当前 AI 设置占位页升级为 NYAWORKS 的 AI 连接与默认行为配置中心，为后续 AI 对话、表达式编写与修复、脚本编写等功能提供统一配置。

AI 设置页负责：

- 配置内置 AI 平台和自定义接口。
- 保存 API Key、接口地址和模型。
- 测试连接并获取可用模型。
- 设置一个全局默认 AI。
- 允许普通对话、表达式和脚本分别覆盖全局默认 AI。
- 管理生成偏好、对话历史和本地数据。

AI 设置页不承担实际对话、表达式生成或脚本生成界面；这些能力由后续 AI 功能页调用统一的 AI 配置服务。

## 2. 核心概念

### 2.1 内置平台

第一版提供以下内置平台预设：

- OpenAI
- Claude
- Gemini
- DeepSeek
- 通义千问
- 豆包
- Kimi
- 智谱 GLM

内置平台提供平台名称、默认接口协议、默认接口地址和连接适配规则。每个内置平台只维护一套用户配置。

内置平台本身不能删除或重命名，但用户可以：

- 启用或停用。
- 修改接口地址。
- 更换或清除 API Key。
- 选择或手动填写模型。
- 清除该平台的全部用户配置。

### 2.2 自定义连接

自定义连接用于：

- OpenAI Compatible 中转接口。
- 公司内部接口。
- 本地模型服务。
- 不在内置平台列表中的其他兼容服务。

每个自定义连接是独立配置实例，支持：

- 新建。
- 重命名。
- 复制。
- 启用或停用。
- 设置为全局默认。
- 删除。

第一版自定义连接统一采用 OpenAI Compatible 协议，不在同一版本中同时扩展多种自由协议编辑器。

### 2.3 全局默认与功能覆盖

用户必须从已保存且启用的连接中选择一个全局默认 AI，默认项由“连接＋模型”共同组成，例如：

```text
DeepSeek / deepseek-chat
```

以下功能默认跟随全局设置：

- 普通对话。
- 表达式：包括表达式编写与修复。
- 脚本：包括脚本编写、修复与解释。

每项功能都可以改为独立的“连接＋模型”组合，例如：

```text
全局默认：DeepSeek / deepseek-chat
普通对话：跟随全局
表达式：跟随全局
脚本：Claude / 已选择模型
```

如果某个覆盖配置被停用、删除或失效，该功能自动回退到全局默认，并在 AI 设置页显示一次非阻塞提醒。

## 3. 页面信息架构

页面延续当前设置中心结构：

- 保留左侧主功能栏。
- 保留顶部五个设置分类图标。
- AI 分类图标进入选中状态。
- 不增加新的内部侧栏。
- 默认面板宽度下不产生横向滚动。

内容区从上到下分为五部分。

### 3.1 当前默认 AI

顶部使用一条紧凑的全宽摘要栏，展示：

- 当前默认连接图标与名称。
- 当前默认模型。
- 连接状态。
- 快速测试按钮。

连接状态使用短文案与小型状态点，不使用大面积提示卡：

- 未配置：灰色。
- 已配置、未验证：黄色。
- 测试中：主题色动态状态。
- 连接正常：绿色。
- 连接失败：红色。
- 存在未保存修改：橙色。

### 3.2 AI 服务

内置平台使用紧凑自适应图标网格：

```text
[OpenAI] [Claude] [Gemini] [DeepSeek]
[千问]   [豆包]   [Kimi]   [智谱]
```

规则：

- 每项只显示统一线性图标、短名称和状态点。
- 当前选中项使用主题色描边。
- 当前全局默认项增加小型默认标记。
- 不使用彩色品牌 Logo，避免视觉混乱和主题不一致。
- 不为每个平台同时展开一套配置表单。

网格下方提供紧凑的自定义连接选择栏：

```text
[ 自定义连接名称 ▼ ] [＋] [···]
```

- 下拉框列出已创建的自定义连接。
- `＋` 打开新建自定义连接窗口。
- `···` 打开当前自定义连接操作菜单。
- 没有自定义连接时，下拉框显示“尚未创建”。
- 下拉菜单宽度遵循已确认的 NYAWORKS 标准，不超出触发框边界。
- 右键点击当前自定义连接打开与 `···` 相同的操作菜单。

### 3.3 当前连接配置

平台网格或自定义连接选择栏只负责选择配置对象。页面始终复用一个配置区，包含：

- 配置名称：仅自定义连接显示。
- API Key。
- 接口地址。
- 模型。
- 启用状态。
- 测试连接。
- 保存配置。

内置平台切换后配置区标题显示平台名称，例如“DeepSeek 配置”；自定义连接显示用户输入的完整名称。

### 3.4 功能模型分配与生成偏好

下方采用非等宽双列布局。

左侧“功能模型分配”：

- 普通对话。
- 表达式。
- 脚本。

每行默认显示“跟随全局”，也可以选择任意已保存、已启用且具备有效模型的连接。

右侧“生成偏好”：

- 创意程度。
- 最大输出长度。
- 流式输出。
- 请求超时时间。
- 失败自动重试。

常用项直接显示；请求超时和重试放入同一区域的折叠高级设置，避免首屏参数过多。

### 3.5 数据与隐私

底部使用一条紧凑的全宽区域：

- 保存对话历史开关。
- 清除对话历史。
- 清除全部 AI 配置与密钥。
- 本地保存说明。
- AE 环境信息附带开关。

“附带 AE 环境信息”默认只允许发送必要的宿主版本、当前任务明确需要的选中内容或错误信息，不自动上传完整工程、素材文件或无关项目数据。

## 4. 模型输入与刷新

模型控件使用可输入组合框，不使用只读下拉菜单：

- 用户可以直接输入任意模型名称。
- 输入框右侧提供刷新按钮。
- API Key 和接口地址填写后，可以请求平台模型列表。
- 请求成功后，用户可从同一个控件的下拉列表选择模型。
- 不支持模型列表接口或请求失败时，仍可手动输入。
- 刷新模型列表不会自动替换当前模型。
- 如果当前手填模型不在返回列表中，继续保留，并标记为“手动填写”。
- 缓存最近一次成功获取的模型列表和时间，重新打开设置页时不自动重复请求。

刷新状态：

- 默认：刷新图标。
- 获取中：图标旋转并禁用重复请求。
- 获取成功：显示短时成功反馈和模型数量。
- 获取失败：显示可理解的错误原因，并保留手动输入能力。

错误信息优先转换为用户可理解的类型：

- API Key 无效或无权限。
- 接口地址不可访问。
- 平台不支持获取模型列表。
- 请求超时。
- 网络不可用。
- 返回格式不受支持。

不直接把冗长原始响应堆到设置页；诊断详情可以复制或在后续诊断入口查看。

## 5. API Key 与保存行为

### 5.1 输入状态

API Key 输入框提供：

- 密文显示。
- 临时显示或隐藏按钮。
- 更换密钥。
- 清除密钥。

已保存的 API Key 重新进入页面时只显示掩码和末尾少量识别字符，不把完整密钥重新写回界面状态或 DOM。

### 5.2 保存按钮

配置区右下角固定提供：

- 测试连接。
- 保存配置。

交互规则：

- 修改任意配置字后，标题旁显示橙色状态点和“未保存”。
- 测试连接使用当前输入内容，不要求先保存。
- 保存不强制要求测试成功。
- 未测试直接保存时，状态为“已配置、未验证”。
- 保存成功显示短时“已保存”反馈。
- 保存失败时保留当前输入，不清空表单。
- 没有任何修改时，“保存配置”置灰。
- 切换平台、切换自定义连接或离开 AI 设置页时，如果存在未保存内容，弹出 NYAWORKS 风格窗口：
  - 保存并继续。
  - 放弃修改。
  - 取消切换。

测试连接成功不会自动保存，避免用户误以为测试等于持久化。

## 6. 自定义连接管理

### 6.1 新建

点击 `＋` 打开 NYAWORKS 自定义弹窗，不调用浏览器、AE 或 Windows 原生输入框。

新建窗口包含：

- 连接名称。
- 协议：第一版固定为 OpenAI Compatible。
- API Key。
- 接口地址。
- 模型。
- 刷新模型。
- 测试连接。
- 创建并保存。

输入规则：

- 名称去除首尾空格。
- 名称不能为空。
- 名称在自定义连接中不能重复。
- 建议限制为 1–32 个字符。
- 接口地址必须为合法的 `http` 或 `https` 地址。
- 本地服务允许 `http://localhost` 和环回地址。

### 6.2 管理菜单

当前自定义连接的 `···` 菜单包含：

- 设为全局默认。
- 重命名。
- 复制连接。
- 启用或停用。
- 删除。

纯图标入口必须提供 Tooltip；菜单项使用图标加短文字。

复制连接时：

- 复制接口地址、模型与生成兼容设置。
- 不复制 API Key。
- 新连接名称自动附加“副本”，用户可以在创建窗口中修改。

删除连接时：

- 使用 NYAWORKS 二次确认窗口。
- 删除密钥引用、缓存模型列表和连接状态。
- 不删除历史对话内容本身。
- 如果连接正在被功能覆盖使用，提示哪些功能会回退到全局默认。
- 如果连接是全局默认，必须先选择其他有效连接；没有可用连接时允许删除，但全局状态变为“未配置”，AI 功能不可发送请求。

### 6.3 内置平台管理

内置平台不显示重命名、复制或删除。

内置平台操作菜单包含：

- 设为全局默认。
- 启用或停用。
- 恢复官方默认接口地址。
- 清除平台配置。

“清除平台配置”会删除 API Key、用户接口地址、模型缓存和当前模型，但保留平台入口。

## 7. 接口适配与请求边界

AI 页面不直接拼接各平台请求。设置系统提供统一的连接服务接口：

```ts
interface AiProviderAdapter {
  testConnection(input: AiConnectionDraft): Promise<AiConnectionTestResult>;
  listModels(input: AiConnectionDraft): Promise<AiModelListResult>;
}
```

平台适配器负责：

- 请求头格式。
- 接口路径。
- 模型列表格式转换。
- 连接测试。
- 错误归一化。

OpenAI Compatible 作为公共适配器；内置平台仅在协议或返回结构不同的情况下提供专用适配器。

所有网络请求必须：

- 设置超时。
- 支持取消。
- 防止连续重复点击。
- 不在日志中记录 API Key。
- 不把 API Key 放入 URL 查询参数。
- 不在错误提示中回显完整响应头或密钥。

浏览器开发预览和真实 AE CEP 宿主的网络能力分别验证。浏览器测试通过不等于 CEP 网络、证书、代理与跨域行为通过。

## 8. 数据结构

非敏感 AI 设置使用独立的版本化存储，不混入通用设置：

```ts
type AiProviderId =
  | "openai"
  | "claude"
  | "gemini"
  | "deepseek"
  | "qwen"
  | "doubao"
  | "kimi"
  | "zhipu";

interface AiConnection {
  id: string;
  kind: "built-in" | "custom";
  providerId: AiProviderId | "openai-compatible";
  displayName: string;
  enabled: boolean;
  baseUrl: string;
  apiKeyRef: string | null;
  selectedModel: string;
  discoveredModels: string[];
  modelsFetchedAt: string | null;
  verificationStatus:
    | "unconfigured"
    | "unverified"
    | "connected"
    | "failed";
  lastTestedAt: string | null;
  createdAt: string;
  updatedAt: string;
}

interface AiModelTarget {
  connectionId: string;
  model: string;
}

interface AiFeatureRouting {
  chat: "inherit" | AiModelTarget;
  expression: "inherit" | AiModelTarget;
  script: "inherit" | AiModelTarget;
}

interface AiGenerationPreferences {
  creativity: number;
  maxOutputTokens: number;
  streaming: boolean;
  timeoutMs: number;
  retryCount: number;
}

interface AiSettings {
  schemaVersion: number;
  connections: AiConnection[];
  globalDefault: AiModelTarget | null;
  featureRouting: AiFeatureRouting;
  generation: AiGenerationPreferences;
  saveConversationHistory: boolean;
  includeAeContext: boolean;
}
```

API Key 不写入 `AiSettings`，只保存不可逆推出密钥内容的 `apiKeyRef`。

## 9. 密钥安全

API Key 不得：

- 明文写入 `localStorage`。
- 出现在首页布局导入导出文件中。
- 出现在日志、截图测试夹具、错误上报或诊断文本中。
- 通过 React 状态长期保留完整值。

实现时建立独立 `AiSecretStore` 接口：

```ts
interface AiSecretStore {
  save(connectionId: string, secret: string): Promise<string>;
  has(reference: string): Promise<boolean>;
  readForRequest(reference: string): Promise<string>;
  remove(reference: string): Promise<void>;
}
```

正式 CEP 环境使用操作系统安全存储适配层：Windows 对接 Credential Manager，macOS 对接 Keychain；安全存储不可用时不得回退到明文持久化，而是提示用户重新输入或仅在本次会话使用。开发预览和自动化测试使用隔离的测试适配器，浏览器预览不得伪装为已经完成安全持久化。

密钥只在发起请求的最短时间内读取，请求完成后不继续保存在页面表单状态。

## 10. 视觉与交互

- 继承极夜青及其他四套已确认主题，不新增 AI 专属配色。
- 继承当前设置页顶部分类胶囊、标题图标、圆角、描边和字体比例。
- 平台图标统一使用单色线性风格，不混用彩色品牌图标。
- 选中态使用主题色描边和克制光效。
- 状态颜色只用于小圆点、短文案和输入反馈。
- 表单控件、下拉框、菜单、弹窗、开关和 Tooltip 复用 NYAWORKS 已确认组件。
- 所有下拉菜单展开宽度不超出触发框边界。
- 不使用 Windows 原生控件。
- 不使用等高大卡片填满页面。
- 不使用占据大量空间的大标题和说明文字。
- 页面允许纵向滚动，但常用配置在默认窗口中应尽量集中显示。

交互动效：

- 平台切换使用短时淡入和轻微位移，不让整页跳动。
- 模型刷新图标在请求期间旋转。
- 保存成功、连接成功使用一次短暂描边反馈。
- 失败只改变局部状态，不晃动整个卡片。
- 遵循通用设置中的“标准 / 减少 / 关闭”动效偏好。

## 11. 国际化

新增文案同步支持：

- 简体中文。
- 繁體中文。
- English。
- 日本語。
- 한국어。

平台品牌名和模型 ID 不翻译；界面标签、状态、错误、按钮、确认窗口和帮助说明必须完整翻译。

英文、日文和韩文下重点验证：

- 自定义连接名称和平台名称不撑破网格。
- 状态文案不挤压模型名称。
- 功能分配下拉框不出现横向溢出。
- 按钮使用短文案，并保留 Tooltip 补充解释。

## 12. 空状态与异常状态

### 12.1 首次进入

- 没有全局默认 AI。
- 所有内置平台显示“未配置”。
- 配置区提示选择平台并填写 API Key。
- AI 功能页发送入口保持不可用，并引导到 AI 设置页。

### 12.2 模型列表为空

- 保留模型手动输入。
- 显示“未获取到模型，可手动填写”。
- 不清除用户之前保存的模型。

### 12.3 网络或接口异常

- 不影响其他设置页和首页。
- 不自动关闭配置窗口。
- 保留用户未保存输入。
- 提供重试和复制诊断信息入口。

### 12.4 密钥不可读取

- 状态改为“需要重新填写密钥”。
- 不删除其他连接字段。
- 依赖该连接的功能回退到全局默认；如果它本身就是全局默认，则暂停 AI 请求。

## 13. 本轮范围

本轮实现：

- AI 设置页面完整视觉与交互。
- 内置平台配置。
- 多个自定义 OpenAI Compatible 连接。
- 模型手填、刷新和选择。
- 保存、未保存保护和连接测试。
- 全局默认和三类功能覆盖。
- 生成偏好。
- 数据与隐私设置。
- 独立设置存储、密钥存储接口和网络适配器结构。
- 五语言同步。
- 自动化测试和浏览器预览验证。

本轮不实现：

- AI 对话页面的真实消息发送。
- 表达式和脚本生成工作流。
- 图片、音频或视频模型。
- 多账号团队同步。
- 云端同步 API Key。
- API Key 导入导出。
- 平台用量和余额统计。
- 自动购买、充值或计费。

## 14. 验收标准

- AI 设置页在默认窗口尺寸下无横向滚动。
- 8 个内置平台可以紧凑展示，切换时共用同一个配置区。
- 内置平台不能删除，自定义连接可以新建、重命名、复制、停用和删除。
- 多个自定义连接通过紧凑选择栏管理，不无限堆叠平台卡片。
- 模型可以手动输入，也可以根据当前 API Key 和接口地址刷新后选择。
- 刷新失败不阻断手动填写。
- 测试连接与保存配置是两个明确且独立的操作。
- 切换连接或离开页面时，不会静默丢失未保存修改。
- 可以设置一个全局默认连接与模型。
- 普通对话、表达式和脚本可以跟随全局或分别覆盖。
