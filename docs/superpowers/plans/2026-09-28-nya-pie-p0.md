# Nya Pie P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the smallest testable second CEP Modeless Extension and shared Action Registry needed to measure the real Nya Pie invocation chain in After Effects.

**Architecture:** Add a multi-entry Vite runtime inside the existing NYAWORKS CEP Bundle. Introduce a small Action Registry, Context Engine, and Action Runner with adapters rather than migrating current tools. The P0 Runtime exercises four-direction selection and a Host test action while explicitly recording the CEP-only capability gaps.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, Adobe CEP 11, ExtendScript

**Spec:** `docs/superpowers/specs/2026-09-28-nya-pie-p0-technical-spec.md`

## Global Constraints

- Do not build the formal Pie Editor, settings, profiles, command palette, effect search, preset search, or third-party script system.
- Do not redesign or regress existing NYAWORKS theme, language, settings, density, update, sidebar, top bar, tooltip, or dialog behavior.
- Do not duplicate AE tool logic in the Pie runtime.
- Do not enable Node.js in CEP.
- Browser and automated validation must remain separate from real AE host acceptance.
- Windows is the P0 priority; AE 2022–2026 and five product languages remain the product compatibility target.

## Review Focus

- Runtime key release when the opening shortcut began outside the Runtime document.
- Missing pre-open global cursor coordinates and absolute window placement.
- AE foreground/focus restoration after Modeless close.
- DPI and multi-monitor coordinate-space mismatch.
- Repeated launch/close calls leaving stale Runtime or Action state.
