# NYAWORKS 当前功能与验证边界

更新日期：2026-10-10。本文承接仓库 README 中较详细的功能清单；具体操作与逐项验收以链接的测试记录为准。**代码已实现、浏览器自动化通过、真实 AE 宿主通过是不同状态**，不能互相替代。

## 首页与共享 Action

- 首页包含锚点、对齐、新建/选择九宫格及工具组；内置“创作通用”布局有 5 个工具组，每组固定 8 个工具位。支持原地编辑、工具添加/替换/移除、组内及跨组拖拽、自定义布局、JSON 导入导出与恢复默认。
- 锚点、对齐、新建图层三套九宫格已接入共享 Action 调用链。首页与全局搜索使用同一 Registry 和执行服务，每次执行前读取 AE 上下文，Host 二次校验并以 Undo Group 修改工程；选择九宫格尚未完成真实宿主功能。
- 全局搜索支持 `Ctrl/⌘ + K`、五语言名称、中文拼音和首字母、方向词及基础模糊匹配。单击选中，双击或 Enter 执行；未实现的首页占位工具不会伪装成可执行结果。
- Banner 可从品牌内容切换到轻量工具工作区。九宫格记忆默认/上次模式；不同密度下保持相同首页结构，仅调整按钮与间距。

## 资源库

- 资源设置支持发现**当前连接的 AE 版本**的内置目录，以及手动添加、编辑、启停和移除自定义来源；不会自动合并另一 AE 版本的目录。
- 资源页按脚本、预设、表达式及文件夹筛选，提供全部/收藏/最近使用视图。宽面板显示可展开的来源与文件夹树，窄面板优先保留资源列表。
- 单击选择，双击或 Enter 执行；右键菜单含类型化动作、收藏、复制路径、定位与默认编辑器打开。已注册 ScriptUI Panel 优先调用 AE 面板命令，未注册时回退执行 JSX；全局搜索复用相同资源命令。
- 目录发现、扫描、文件选择及脚本/预设/表达式/面板执行有真实 AE 宿主测试反馈；完整操作与待补结果在[资源命令检查表](testing/resource-command-ae-test.md)。云端目录和临时渲染预览未实现。

## 设置、界面与实验能力

- 五套暗色主题、简体中文/繁體中文/English/日本語/한국어、三档界面密度；常规设置包括启动页、上次页面、界面亮度、提示、动效、更新检查和安全重置。
- AI 设置页可管理八个内置平台与自定义 OpenAI Compatible 连接、模型字段和生成偏好；正式 CEP 安全存储与真实平台联网仍待单独接入和验收，不能把设置界面当成已可用的 AI 助手。
- GitHub Releases 检查和“本次更新”提示已接入；当前不自动下载、安装或升级扩展。
- Nya Pie P0 只有四方向调用链探针；Windows NyaLauncher P1 是定位/无边框候选，**不是正式 Pie UI 或 Pie Editor**。见[P0](testing/nya-pie-p0-ae-test.md)和[P1](testing/nya-launcher-p1-ae-test.md)测试记录。

## 验证与发布原则

- Windows AE 2025 的局部宿主测试不等于 AE 2022–2026 全版本、不同系统语言或 macOS 兼容。扩展仍按开发预览维护，不在 README 中提供面向普通用户的正式安装入口。
- 浏览器预览、TypeScript、Vitest、生产构建和 `dist` 冒烟检查证明工程与模拟交互边界，不替代用户真实 AE 工程验收。
- 日常开发使用唯一 `dev-extension/` 和 CEP junction，不为每个工具制作独立测试包；`release/` 的旧目录是历史阶段快照。

产品开发顺序见[核心工具路线](../planning/05-core-tools-priority-roadmap.md)；逐项进度见[开发路线](../planning/02-roadmap.md)。当前仓库说明见[README](../README.md)。
