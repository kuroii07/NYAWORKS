用户开启自动移动、设置速度 190，播放仍无运动；随后确认控制空对象的原生 Position 从 0 秒到 2 秒没有变化。此前手动位置偏移已经能带动画面。这将故障范围缩小到控制器位置表达式的自动移动分支，不能再用首帧时间为零解释，也不能归因于摄像机未跟随已经运动的控制器。

## 单一假设与最小修订

旧表达式使用未声明的 `speed=effect(1)(14)`，随后计算 `time*speed`。当表达式上下文已经暴露只读 `speed` 属性时，赋值不会建立独立的速度变量：原生速度为零会使自动位移始终为零。

新增用例为实际生成的位置表达式提供只读 `speed=0` 和 `speed=35` 上下文。旧代码两例均失败：速度控件 190、时间 2 秒时，预期 Z 从 30 增至 410，实际分别为 30、100。这证明旧表达式存在同名属性冲突风险，**不证明用户当前 AE 实例一定沿此路径执行**。

本次仅将自动移动速度改为显式声明的独立变量 `var nyaMotionSpeed`，乘法使用该变量。时间规则仍是合成时间乘速度；没有改变参数、默认值、范围、伪效果身份、FFX 数据、目标、重置或手动偏移。未使用的旧原生效果创建函数不在本次改动范围。
