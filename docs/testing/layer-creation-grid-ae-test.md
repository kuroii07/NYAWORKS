### 文字

- [x] 普通点击创建内容为小写 `text`，且图层名跟随源文字内容；
- [x] 锚点在文字边界中心，图层居中；
- [x] 先在 AE 切换最近使用字体，再创建文字，确认继承该字体；
- [x] 没有最近字体状态时使用 AE 默认字体；
- [x] `Alt + 点击` 打开独立文字编辑器，普通点击不受影响；
- [x] `读取`、编辑内容、`应用` 可更新已读取文字层，`创建` 可新建文字层；
- [x] 编辑器支持正常输入，并跟随主面板主题与五种语言状态；
