## 九个 Action

### 文字

- [ ] 内容为小写 `text`；
- [ ] 锚点在文字边界中心，图层居中；
- [ ] 先在 AE 切换最近使用字体，再创建文字，确认继承该字体；
- [ ] 没有最近字体状态时使用 AE 默认字体；
- [ ] 修饰键不会切换到另一种文字创建模式。

### 纯色

- [ ] 创建真正的黑色 Solid，尺寸和像素比例匹配合成；
- [ ] Effect Controls 中存在可直接调色的原生 `Fill` 效果；
- [ ] 修饰键不会改变纯色层创建行为。

### 形状

- [ ] 默认 500×500、圆角 50、合成居中、锚点位于形状中心；
- [ ] `Nya 宽度`、`Nya 高度`、总圆角、独立四角开关和四角数值实时有效；
- [ ] `Alt` 圆形、`Ctrl` 三角形、`Shift` 星形；
- [ ] 图层命名为 `Nya 圆角矩形`、`Nya 圆`、`Nya 三角形`、`Nya 星形`；
- [ ] 圆使用半径；三角形使用半径/旋转/圆角；星形使用角数/内外半径/旋转/内外圆角；
- [ ] 各变体只显示实际有效的中文控制参数，表达式无错误。

### 调整层

- [ ] 创建真正的 Adjustment Layer，不自动添加效果。

### 空对象

- [ ] 所有 Null 都是 guide layer，锚点位于 Null 中心；
- [ ] 无选中时位于合成中心；
- [ ] 单选/多选建立父子关系后，原图层画面位置不跳动；
- [ ] `Alt` 为每个选中图层建立独立 Null；
- [ ] `Shift` 创建 3D Null。
- [ ] 重名时按 `Nya 控制`、`Nya 控制 2`、`Nya 控制 3` 递增。

### 摄像机

- [ ] 默认创建 `Nya 摄像机控制` 与 `Nya 摄像机`，控制器位于摄像机上方；
- [ ] 控制器为 3D guide layer，摄像机为 35mm 且绑定控制器；
- [ ] 目标图层、位置、旋转、自动移动、镜头、焦点和抖动中文控件实际驱动摄像机；
- [ ] `Ctrl` 打开 AE 原生摄像机设置窗口；
- [ ] 三键组合不再打开模式菜单。

### 灯光

- [ ] 默认点光源；
- [ ] `Alt` 聚光灯、`Ctrl` 平行光、`Shift` 环境光。
- [ ] Position / Point of Interest 位于合成视觉中心。

### 预合成

- [ ] 选中索引顺序不同仍得到正确预合成；
- [ ] 默认移动全部属性，新合成时长为选层最早入点到最晚出点；
- [ ] `Alt` 支持单选和多选，并按选层视觉边界裁切新合成尺寸；
- [ ] `Alt+Ctrl+Shift` 创建后打开新预合成的合成设置；
- [ ] 新预合成层被选中，一次 Undo 恢复。

### 解预合成

- [ ] 简单单层预合成可展开，内部顺序和时间正确；
- [ ] AE 默认存在但未启用的 Layer Styles 组不会误报；
- [ ] 真正启用的图层样式、非默认缩放/旋转、效果、遮罩、3D、父级、时间重映射、裁剪、禁用/静音、Solo、运动模糊、帧混合、保留透明度、混合模式、参考线/调整层、非 100% stretch、折叠变换或轨道遮罩依赖均安全拒绝；
- [ ] Alt 裁切预合成可以解开，并正确恢复空间偏移；
- [ ] 内部包含摄像机、灯光、锁定层、跨层依赖或引用 `thisComp` / `comp()` 的表达式时安全拒绝；普通可复制表达式应保留；
- [ ] 所有拒绝都不改变父合成；
- [ ] 中途复制失败不会删除原预合成或留下可见半成品。
