## 通用矩阵

分别用合成起始时间 `0` 和非 `0` 测试：

- [ ] 无选中：创建到最上方，覆盖完整合成时间；
- [ ] 单选：插入选中层上方，匹配该层入点/出点；
- [ ] 多选且选择数组顺序与图层索引不同：插入最上方选中层之前，匹配最早入点到最晚出点；
- [ ] 创建后只选中新结果；
- [ ] 一次 Undo 完整撤销；
- [ ] 中文 AE 与 English AE 都不依赖显示名称；
- [ ] 锁定、父级和混合 2D/3D 场景不产生半成品。

## 九个 Action

### 文字

- [ ] 内容为小写 `text`；
- [ ] 锚点在文字边界中心，图层居中；
- [ ] 先在 AE 切换最近使用字体，再创建文字，确认继承该字体；
- [ ] 没有最近字体状态时使用 AE 默认字体。

### 纯色

- [ ] 创建真正的黑色 Solid，尺寸和像素比例匹配合成；
- [ ] Effect Controls 中存在 `Fill`，颜色为黑色。

### 形状

- [ ] 默认 500×500、圆角 50、合成居中、锚点位于形状中心；
- [ ] 宽、高、总圆角、独立四角开关和四角比例实时有效；
- [ ] `Alt` 圆形、`Ctrl` 三角形、`Shift` 星形；
- [ ] 各变体只显示实际有效的控制参数，表达式无错误。

### 调整层

- [ ] 创建真正的 Adjustment Layer，不自动添加效果。

### 空对象

- [ ] 所有 Null 都是 guide layer，锚点位于 Null 中心；
- [ ] 无选中时位于合成中心；
- [ ] 单选/多选建立父子关系后，原图层画面位置不跳动；
- [ ] `Alt` 为每个选中图层建立独立 Null；
- [ ] `Shift` 创建 3D Null。

### 摄像机

- [ ] 默认创建 `Nya Camera Controller` 与 `Nya Camera`；
- [ ] 控制器为 3D guide layer，摄像机为 35mm 且绑定控制器；
- [ ] 位置、旋转、焦距、景深和点聚焦控件实际驱动摄像机；
- [ ] `Alt` 只创建摄像机，不弹出 AE 设置窗口。

### 灯光

- [ ] 默认点光源；
- [ ] `Alt` 聚光灯、`Ctrl` 平行光、`Shift` 环境光。

### 预合成

- [ ] 选中索引顺序不同仍得到正确预合成；
- [ ] 默认/`Ctrl` 移动全部属性；
- [ ] `Alt` 只允许单层保留属性，多选时安全拒绝；
- [ ] 新预合成层被选中，一次 Undo 恢复。

### 解预合成

- [ ] 简单单层预合成可展开，内部顺序和时间正确；
- [ ] 外层非默认变换、效果、遮罩、图层样式、3D、父级、时间重映射、裁剪、禁用/静音、Solo、运动模糊、帧混合、保留透明度、混合模式、参考线/调整层、非 100% stretch、折叠变换或轨道遮罩依赖均安全拒绝；
- [ ] 内部包含摄像机、灯光、锁定层、表达式或跨层依赖时安全拒绝；
- [ ] 所有拒绝都不改变父合成；
- [ ] 中途复制失败不会删除原预合成或留下可见半成品。
