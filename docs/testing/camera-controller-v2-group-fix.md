# 摄像机 v2 分组结构修正候选

日期：2026-10-15。状态：用户已确认 v2 可以正常控制画面，截图显示位置及旋转联动；随后报告位置拖动过敏、效果重置导致画面移出。后两项的修订见 [v3 位置偏移与重置](camera-controller-v3-position-reset.md)。本页保留 v2 首次交付的结构修复和验证记录，不代表其所有参数、语言均已验收。未提交、未推送，未操作 AE。

## 已确定的问题

用户确认直接改摄像机位置、直接改父级空对象的原生位置均能带动画面。通过 AE 表达式关联器生成的 `effect("Nya 摄像机控制")("Nya 相机旋转 X")` 仍触发 `invalid index in indexed group`。因此故障集中在伪效果参数访问，不能继续归因为父级绑定或仅凭替换表达式名称/数字索引宣称修复。

读取四种语言实际交付的 FFX 参数定义，均发现 **6 个组起始（kind 13）、7 个组结束（kind 14）**。生成器在每组结束后，又把版本 marker 追加成第 7 个结束项。第 28 项没有对应的组起始；原来已通过的四形状预设使用最后一个合法组结束项作为 marker，不存在这个多余结束项。

这是可从源代码和二进制共同确认的结构错误，与 AE 的索引组报错相符；仍不能仅凭离线修正就确定它解释了全部历史症状或此前的渲染诊断崩溃。

## 候选改动

| 项目 | v1 | v2 |
| --- | --- | --- |
| 用户参数 | 15 项 | 15 项，全部名称、默认值、范围、语义索引不变 |
| 分组 | 6 个起始、7 个结束 | 6 个起始、6 个结束 |
| marker 所在属性索引 | 28，多余结束项 | 27，第六组已有结束项 |
| FFX 定义与数据流数量（含系统输入） | 29 | 28 |
| 效果身份 | `Pseudo/NYA_Camera_v1_*` | `Pseudo/NYA_Camera_v2_*` |
| Host 修订 | `camera-rig-host-20261015-2` | `camera-rig-host-20261015-3` |

v2 具有独立身份，因为结构布局确实改变；不是用换名代替修正。已保存工程中的 v1 实例不自动迁移，也不批量删除。坏预设存于 `assets/pseudo-effects/camera/v1/rejected/`，仅作为离线回归材料，不进入扩展。

四种语言 v1/v2 的前 27 项定义和数据流逐字节一致；更改限于末尾 marker/结束项、相应数量和身份。未修改目标图层流的未知字段、现有表达式公式、父级逻辑、四形状资产或它们的 Catalog 条目。韩文仍保持当前明确不可创建的行为，不声称恢复了五语言交付。

生成器在写出任何摄像机预设前，检查定义/数据流数量与顺序一致、分组结束不下溢、分组最终闭合，并支持输出到独立目录验证可重复构建。
