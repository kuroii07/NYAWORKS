1. `Layer_Test`：1920×1080、20 秒，起始时间先用 0，再用 5 秒。准备两个 AE 原生普通 2D 图层 A、B，尺寸和位置不同，无父级、效果、遮罩、表达式或关键帧。起始时间 5 秒时，A 入出点设为 6–18 秒，B 为 8–12 秒；让选择顺序与上下层顺序不同。调整层另检查像素长宽比 1.5。
