### 2026-10-10 半径变化后描边被填充遮盖

用户在真实 AE 中发现开启描边、设置宽度后调整半径，填充会盖住描边。Host 原先在同一矢量组内先添加 Fill，再添加 Stroke；AE 从时间线下往上绘制同组运算符，因此 Fill 位于 Stroke 上方。此次仅交换**新建圆形**的运算符创建顺序，使 Stroke 位于 Fill 上方，仍在全部添加后重新取得属性引用，不改动圆角矩形的现有创建路径。先新增运算符顺序回归测试并观察失败，修改后相关 3 文件 / 52 项通过；类型检查、构建、`smoke:dist` 以及排除旧工作树后的全量 130 文件 / 693 项通过。既有图层不会自动重排 Contents；真实 AE 中的新建圆形描边是否完整显示、半径 50/250/500 与描边宽度 5/100/500 组合以及保存重开，仍需复测。
