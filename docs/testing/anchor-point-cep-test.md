# 锚点九宫格 CEP 实测说明

## 测试包

构建后的测试扩展位于：

`release/NYAWORKS-0.1.0-alpha.1-anchor-test/`

## 安装

1. 关闭 After Effects。
2. 将整个 `NYAWORKS-0.1.0-alpha.1-anchor-test` 文件夹复制到 CEP 扩展目录。
3. 在 Windows 注册表中启用 CEP 调试模式后重新打开 AE。
4. 在 AE 的“窗口 / 扩展”菜单中打开 `NYAWORKS`。

本次构建的扩展 ID 是 `com.kuroii.nyaworks.panel`，清单已允许 AE 18.0 及以上版本。

## 锚点功能范围

- 支持当前合成中选中的普通 2D 图层。
- 支持开启三维开关的普通 3D 图层；九宫格调整 X/Y 锚点并保留 Z 值。
- 支持多选图层。
- 每次操作使用一个 AE Undo Group，可直接撤销。
- 修改后使用画面位置补偿，目标是保持内容在合成中的视觉位置不跳动。

## 当前明确跳过的情况

- 没有选中图层；
- 摄像机、灯光等非普通内容图层；
- Anchor Point 或 Position 含表达式；
- Anchor Point 或 Position 已存在关键帧；
- 分离维度 Position；
- 锁定图层或无法建立稳定坐标补偿的复杂场景。

## 建议验收顺序

1. 2D 固态层：依次点击左上、中心、右下，确认内容位置不跳动。
2. 文字层和形状层：确认边界按内容区域计算。
3. 开启三维开关的普通图层：确认九点锚点生效，Z 锚点和 Z Position 不被改写。
4. 多选 2D/3D 图层：确认一次操作可以批量执行。
5. 使用 Ctrl/Cmd+Z：确认一次撤销可以还原整批图层。
