## 已确定的交互

- 单选一个图层，普通点击：对齐到合成。
- 单选一个图层，按住 Alt / Option 或 Shift 点击：仍对齐到合成。
- 选择两个及以上图层，普通点击：按全部选中图层的联合边界对齐。
- 选择两个及以上图层，按住 Alt / Option 或 Shift 点击：强制对齐到合成。
- 下排三个按钮修改文字段落的左对齐、居中、右对齐，不使用合成或选区目标。
- 首页与全局搜索执行同一组 Action；全局搜索不带修饰键，自动使用上述单选 / 多选规则。
- 图层未开启 3D 开关时使用 2D 边界与父级二维坐标换算。
- 图层开启 3D 开关时使用当前相机的屏幕投影边界，反算 Position X/Y，并保持 Position Z 不变。
- 2D / 3D Position 含关键帧或表达式时仍安全拒绝，不覆盖现有动画。

## 建议验收步骤

1. 新建一个合成，放入一个尺寸明显小于合成的普通 2D 图层。
2. 依次点击上两排六个图层对齐按钮，确认左、水平居中、右、上、垂直居中、下均对齐到合成。
3. 单选时分别按住 Alt 和 Shift 重测任意两个按钮，确认结果仍是合成对齐。
4. 选择两个尺寸、位置不同的图层，普通点击六种图层对齐，确认它们按选区联合边界互相对齐。
5. 保持多选，按住 Alt 或 Shift 点击六种图层对齐，确认所有图层改为对齐合成边界。
6. 对开启 3D 开关的图层测试六个方向，确认依据当前相机最终画面对齐，且 Position Z 不变。
7. 对带 3D 父级、父级缩放或旋转的子图层重复测试，确认仍按屏幕边界对齐。
8. 给 Position 添加关键帧或表达式，确认动作安全拒绝并显示明确提示，不破坏现有动画。
9. 锁定图层后执行，确认显示锁定提示；摄像机、灯光等不支持图层应显示不支持提示。
10. 分别选择点文字和段落文字，依次测试下排左、中、右三个段落按钮。
11. 同时选择多个文字图层，确认每个文字图层均更新；混入普通图层时，文字层继续更新，普通图层保持不变。
12. 锁定一个文字层并与未锁定文字层同时选择，确认未锁定文字层继续更新，锁定层保持不变；只选择锁定文字层时应显示锁定提示。
13. 给 Source Text 添加关键帧，在时间指针所在位置执行左、中、右对齐，确认当前时间的文字值更新且其他关键帧保持不变。
14. 按 `Ctrl/Command + K` 搜索“左对齐”“水平居中”“段落居中”等词，执行后确认结果与首页一致。
15. 对每种成功操作执行一次 Undo，确认一次撤销恢复本次操作。
16. 不选择图层时从首页和全局搜索执行，确认均提示先选择图层。
