# 摄像机控制器伪效果候选验证记录

日期：2026-10-12。实施分支：`feat/camera-controller-pseudo`。本记录对应新建摄像机；旧工程里的 15 个原生效果控件不迁移。

## 候选行为

- 普通点击或 Ctrl 点击先从扩展目录预检 `camera.rig/v1/<面板语言>`；然后新建 35mm 摄像机及 3D guide 控制器，在控制器上应用一份六组、15 项伪效果。三个位置参数在新建时设为所选图层平均位置；无有效选层时为合成中心。摄像机局部位置为 `[0,0,-1000]`。
- 控件由 Catalog 中的语义 ID 和固定属性索引绑定。镜头、景深、目标、对焦、旋转、位置、自动移动和抖动继续驱动原功能；自动移动仍按 `time × speed`。摄像机表达式通过自身 `parent` 定位所属控制器，避免同名控制器或重命名错绑。
- 创建前缺少某语言模板会明确失败；中途模板、参数、表达式或 Ctrl 设置失败则移除本次两层并恢复原选层。韩文模板在中文 AE 中显示乱码，**不在交付目录和 Catalog 中**；韩文面板下的新建摄像机会在创建前明确失败，不静默套用英文或中文控件。

## 仍需真实 AE 验收

1. 在独立空白工程逐个创建简中、繁中、英文、日文摄像机；核对六组、15 项、位置默认值、35mm、景深和焦距，并确认 `expressionError` 为空。韩文须确认创建前提示且无残留层。
2. 指定目标层、开启自动对焦、删除目标层；检查目标点和焦距回退。测试移动开关和正负速度、强度/频率为 0 的抖动、三个旋转、关键帧、允许键入的上下界及非零起始时间。
3. 同一合成创建多组摄像机，复制并重命名控制器、摄像机；检查各组表达式仍引用自身父控制器。验证 Ctrl 原生设置、撤销/重做、保存重开与故障清理。
4. 在中文/英文 AE、AE 2022–2026 目标版本及 Windows/macOS 条件允许时复测。面板按钮和真实 CEP 安装路径需要单独验收。

韩文可读 `.ffx` 尚未制成；在有可读候选或用户批准其他兼容策略前，不宣称五语言交付完成。
