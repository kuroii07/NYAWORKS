# 空对象优化验收

日期：2026-10-11。基线：`31b65ba`。本轮为 Windows 开发候选，真实 AE 验收待完成。

## 使用方式

- 普通点击：无选层时创建居中的 2D guide Null；有 2D 选层时放在选层几何边界并集中心，统一关联选层。
- Alt：每个选层创建独立控制器，放在该层锚点位置，保持该层的 2D/3D 类型及时间范围。
- Ctrl：创建共享控制器，位置取选层锚点的算术平均值。
- Shift：创建共享 3D 控制器；全为 2D 选层时仍取几何边界中心。
- 选层含 3D 时，共享控制器自动为 3D，位置取世界空间锚点平均值，避免把相机投影坐标作为 3D Position；不使用屏幕投影边界中心。
- 组合修饰键沿用当前默认模式，不新增组合模式。所有 Null 锚点居中，名称跟随面板语言并递增；创建后只选中控制器。共享控制器使用选层时间并集，放在最上方选层之前。

边界中心采用 `sourceRectAtTime`/素材尺寸及图层变换，不承诺包含蒙版、效果扩展和最终渲染像素。Alt/Ctrl 使用图层锚点，可能与图形几何中心不同。

## 安全与恢复

沿用已有父级安全拒绝；锁定层同样在创建前拒绝，不替换已有层级。位置、锚点、缩放、旋转、方向等变换含关键帧或启用表达式时，本轮暂不自动关联；支持静态分离维度 Position。透明度动画等不影响空间变换的属性无需拒绝。

整批预检通过后才创建。关联使用 AE 原生 `.parent` 补偿；Local Position 数值可以改变，画面位置应保持。初始化、插入或关联失败时移除本次新增 Null、恢复尝试关联的原父级/变换及原选区。恢复失败时明确提示用户立即 Undo 并检查层级，不伪报恢复成功。一个操作保留一个 Undo Group。
