## 这次修了哪里

1. **灯光初始化和名称。** 旧代码给所有类型写空间属性，并统一使用“灯光”名称。本次环境光不写位置/目标，点光不写目标，聚光和平行光使用实际目标属性；初始化失败清理新灯光。五语言均有四种类型名称。模拟测试复现了不可写属性的失败，但原截图没有完整原生异常文本，不能据此断言已确认全部实机根因。
2. **时间二次偏移。** 旧代码设置 `startTime` 后，再从已联动的入出点继续减/加偏移。本次先保存三个原值再写入，覆盖预合成裁时长和解预合成。新测试模型包含时间联动；旧模型没有暴露这一问题。
3. **裁切坐标。** 支持的 2D 裁切使用图层到合成的二维变换，并在读取形状边界时包含 extents；不再将屏幕投影边界当作内部图层坐标。截图中的 3D 场景尚未完成可靠裁切，当前只提前拒绝。裁切使用当前帧几何边界，不保证覆盖整段运动、效果扩张或最终渲染像素。
4. **解预合成半成品。** 测试改为真正增删、重排的图层集合，覆盖 `copyToComp` 无返回值，以及插入新层后才抛错的情形。内部子层保留本地变换，空间偏移只加到根层；失败时重新读取集合、清理全部新增层。清理失败会明确提示一次 Undo，避免静默留下半成品。原截图的具体失败阶段未知，修订仍需 AE 验证。

Ctrl 逐层预合成中途失败时，原生操作可能已经移动部分内容，因此保留结果并明确提示一次 Undo 恢复整批。复杂跨层引用、3D 渲染、Undo/Redo 和保存重开不能由本地模拟保证。
