日期：2026-10-15。Windows 测试候选，等待用户在 AE 中验收拖动和重置手感。未提交、未推送，不启动或自动操作 AE。

后续目标选择框修订见 [目标选择与跟随修正](camera-controller-v3-target-selector.md)。本页保留位置偏移首次交付的版本和哈希，后续版本保持这里的位置规则。

## 用户反馈与原因

用户先确认 v2 能正常控制画面，随后报告轻微拖动位置就使图层移出画面。第二组截图显示，点击效果顶部「重置」后，三个位置控件和控制器 Position 都变成 `[0,0,0]`，画面变黑。

v2 的位置控件默认值是 0，创建逻辑却将合成中心或选层平均坐标直接写入控件，表达式也直接把控件当作绝对位置。1920×1080 空选层创建时是 `[960,540,0]`；重置到 0 就会将控制器带离创建时的位置。不是图层被删除。

旧拖动范围 X/Y 为 ±10000、Z 为 ±20000。此次收窄 UI 范围；具体鼠标手感仍需 AE 内验证，不把范围缩小倍数当作已测量的拖动速度。

## 当前规则

| 参数 | 初始值/重置值 | 拖动范围 | 有效输入范围 |
| --- | --- | --- | --- |
| 位置偏移 X | 0 | -500～500 | -100000～100000 |
| 位置偏移 Y | 0 | -500～500 | -100000～100000 |
| 位置偏移 Z | 0 | -500～500 | -100000～100000 |

原生 Position 保存合成中心或选层平均位置。表达式读取原生属性的表达式前值，再加上三轴偏移；X=10 表示在基准位置上移动 10，不额外乘缩放系数。效果重置将偏移归零，不重置原生位置。不同合成尺寸、非零 Z 及小数坐标不写死。以后若手动调整原生 Position，它就是新的基准位置。

自动移动仍叠加在 Z 轴，抖动、旋转、镜头及对焦公式保持既有逻辑。6 个组、15 项参数索引、28 条定义/数据流、marker 索引 27 和摄像机局部位置 `[0,0,-1000]` 均不变。

因为位置由绝对坐标变为偏移量，使用独立 `camera.rig/v3/<locale>`、`Pseudo/NYA_Camera_v3_*` 和 `__NYA_CAMERA_V3__`，避免旧控件坐标被当成新偏移，也隔离已经加载的旧定义。Host 修订为 `camera-rig-host-20261015-4`。旧实例不自动迁移。韩文继续在创建前拒绝；本次未扩展语言范围。
