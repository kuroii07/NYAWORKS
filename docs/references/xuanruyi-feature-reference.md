# 玄如意功能参考基线

来源：[玄如意使用教程](https://my.feishu.cn/wiki/Sxfcw2XldiRMXzkj9Ltc7FkencW)
本次核对日期：2026-10-05
适用范围：NYAWORKS 当前及未来全部工具，不限于新建图层九宫格。

## 1. 文档定位

这份资料是 NYAWORKS 的长期竞品与工作流参考，不是待照搬的功能清单，也不只服务于某一个页面。

以后设计项目、合成、图层、动画、文字、图形、效果、媒体、参考线、属性、素材管理或其他 AE 工具前，都应先查询原教程中对应分类，理解它解决的实际操作问题，再决定 NYAWORKS 是否需要实现以及怎样升级。

参考边界：

- 可以研究功能目的、操作顺序、修饰键、批处理方式和用户反馈；
- 不复制其 UI、代码、命名、图标组合或完整行为；
- 不因参考资料中存在某项功能，就默认把它加入 NYAWORKS；
- 不增加缺少明确 AE 使用场景的详情页、健康度或管理负担；
- NYAWORKS 的实现必须服从自己的 Action、Host、安全、兼容和视觉规范。

这里的“全部工具”是项目级规则：不仅是本轮新建图层，后续首页快捷工具，以及项目、合成、图层、动画、文字、图形、效果、媒体、资源管理和其他功能页中的每一项正式工具，都应在规划阶段查询对应教程。尚未开发的分类只建立检索入口并标记“待核对”，不能因为建立了本文就视为已经完成逐工具研究。

## 2. 每项工具的强制分析方法

设计新工具时，在规格中至少填写以下五项：

```text
参考行为 → 它在 AE 中解决什么高频问题
真实场景 → 哪类用户在什么上下文中会使用
保留价值 → 哪个核心动作值得保留
NYAWORKS 升级 → 怎样减少步骤、增强批量能力或提高安全性
拒绝冗余 → 哪些选项、面板或信息不应加入
```

逐工具记录使用以下模板，放入对应功能规格或本文“当前已核对”章节：

```text
工具名称 / 来源分类：
核对日期 / 来源页面：
核对状态：已核对 / 待复核 / 待核对
参考行为：
真实 AE 场景：
保留价值：
NYAWORKS 升级：
拒绝冗余：
计划 Action ID / 多入口：
Host 安全与兼容边界：
```

落地后还必须检查：

- 是否注册为稳定 `actionId`，供首页、功能页、全局搜索、快捷键和 Nya Pie 复用；
- 前端是否只负责入口、交互和反馈，实际 AE 修改是否在 Host 完成；
- Host 是否重新校验活动合成、选层、属性和危险条件；
- 是否支持一次 Undo；
- 批量行为、修饰键和失败原因是否可解释；
- 中文/英文 AE、AE 2022–2026+、Windows/macOS 差异是否已考虑；
- UI 是否比参考更紧凑、清晰且不堆叠伪功能。

## 3. 来源分类与后续路由

飞书教程当前可见的主结构如下。分类是检索入口，不等于 NYAWORKS Roadmap。

| 来源分类 | 已观察内容 | NYAWORKS 使用方式 |
|---|---|---|
| 主页 / 应用中心 | 主页聚合、浮动模块、应用中心集中全部功能、网格/列表和功能复用 | 研究多入口调用；统一消费 Action Registry，不建立第二套工具系统 |
| 项目工具 | 当前公开页未展开具体条目，待开发对应功能时重新核对 | 关注项目项、文件夹、依赖与破坏性操作边界，不从其他分类臆测行为 |
| 图层工具 | 拆文本、图层偏移、对齐分布、选择、排序、分布、复制/粘贴/删除、父级、连续父子级、镜像、标签 | 优先高频、可批量、可撤销的图层动作；对破坏性和跨层依赖加强预检 |
| 合成工具 | 复制合成、层层预合成、合成裁剪、参考线、音频通用、合成填图、合成设置 | 把可复用能力注册为合成 Action；区分普通多层预合成与逐层预合成 |
| 新建图层 | 文字、纯色、形状、调整层、空对象、摄像机、灯光 | 作为本轮九宫格参考；统一选层范围、时间范围、插入位置和修饰键 |
| 参考线 | 合成辅助与参考线相关工具 | 优先非破坏式操作，并区分 AE 参考线与 guide layer |
| 动画生成 | 动画生成分类 | 后续逐项核对，不预先复制参数面板；优先可复用动画 Action 与预设体系 |
| 属性工具 | 属性相关操作分类 | 优先 Match Name、选中属性上下文、关键帧/表达式安全和批量结果反馈 |
| 文字工具 | 当前可见条目主要出现在图层“拆文本”，独立文字分类待后续核对 | 关注 TextDocument、段落/点文字、字体继承、逐字拆分与多语言文本风险 |
| 图形工具 | 当前可见条目主要出现在参数化形状，独立图形分类待后续核对 | 关注 Shape match name、路径表达式、锚点和可编辑参数，避免无效控件 |
| 效果工具 | 当前公开页未展开具体条目，待开发对应功能时重新核对 | 以 match name、效果顺序、重复添加策略和跨语言兼容为准 |
| 媒体工具 | 素材管理入口可作为相关参考，独立媒体分类待后续核对 | 区分项目素材操作与磁盘资源管理，复用统一资源命令和路径兼容层 |
| 其他工具 | 跨分类辅助工具 | 只有明确高频价值时才纳入，避免成为杂项堆放区 |
| 素材管理 | “使用、收集于一体”的素材管理入口 | 对照 NYAWORKS 资源页实际工作流，复用资源索引与统一命令，不增加无意义详情 |

## 4. 当前已核对的具体行为

以下条目已经从公开教程页面或配图中核对，可作为设计事实；未列出的细节不得靠猜测补齐。

### 4.1 应用中心与入口复用

- 所有功能集中在应用中心；
- 应用中心支持网格/列表展示；
- 功能按钮可以加入主页的自定义按钮分组。

NYAWORKS 的升级方向：功能定义只保留一份，由 Action Registry 同时提供给九宫格、首页布局、全局搜索和未来 Nya Pie。

### 4.2 图层新建

- 已观察到形状、空对象、纯色、文本、灯光、相机、调整层等新建类型；
- 形状创建后有控制器，可调整圆角，并支持四角独立参数；
- 多选图层后创建空对象时，会围绕选择区域并支持批量创建；
- 摄像机默认带表达式控制，`Alt` 用于创建纯摄像机。

NYAWORKS 的升级方向：统一无选中/单选/多选时间和插入规则；所有 Null 默认 guide layer；摄像机控制器使用稳定效果控件和安全父级；Tooltip 只展示已经实现的变体。

### 4.3 图层与合成

- “拆文本”通过文字转形状获得字符位置，再复制文字层并同步样式与位置；教程同时提示可视范围和局部样式获取风险；
- “层层预合成”会对每个选中图层分别执行预合成；
- 把多个选中图层合并到一个预合成，仍使用 AE 原生 `Ctrl+Shift+C`；
- 合成裁剪在新版本中依赖外部 Auto Crop 插件。

NYAWORKS 的升级方向：在实现前明确单一预合成、逐层预合成和普通多层预合成的区别；外部依赖必须显式说明且有缺失状态；拆文本类功能必须把已知失真风险转成 Host 预检和可解释拒绝。

## 5. NYAWORKS 的升级标准

在参考功能基础上，至少满足一项升级价值才进入开发：

1. 减少实际点击或重复操作；
2. 把单层操作安全扩展为多选批量操作；
3. 用统一 Action 支持多个入口，而不是复制实现；
4. 对锁定、父级、3D、表达式、关键帧、时间关系等增加安全校验；
5. 改善窄面板、Tooltip、键盘操作、错误反馈或多语言；
6. 去掉低频参数、重复筛选、无内容详情或不必要弹窗；
7. 在不破坏 AE 原生习惯的前提下提供更好的默认值。

如果一项参考功能只会增加界面层级、维护成本或理解成本，却不能改善真实创作流程，应记录为“拒绝冗余”，不进入实现。

## 6. 后续维护

- 本文记录长期方法和已经核对的事实，不替代具体功能规格；
- 每次正式开发新分类前，重新打开来源页面核对对应条目，避免依赖过时截图；
- 新增观察必须注明核对日期，不确定内容标记为“待核对”；
- 功能是否进入 Roadmap，以用户需求、实际 AE 价值和 NYAWORKS 项目规划为准。
- “参考方法和分类入口已建立”可以标记完成；“全部工具逐项核对”是随开发持续推进的工作，不提前标记完成。
