# NYAWORKS / 喵创问题反馈表单

> 本文件用于创建飞书表单。创建后建议开启外部用户填写，并关闭“填写者可查看其他提交内容”。

## 表单标题

NYAWORKS / 喵创问题反馈

## 表单说明

感谢你帮助改进 NYAWORKS。请尽量完整描述问题并提供复现步骤；如果问题涉及项目文件或隐私内容，请先进行脱敏处理。

提交后，开发者会根据影响范围、复现稳定性和开发阶段安排处理。早期开发版本中的占位功能不属于故障。

## 字段设计

### 1. 反馈类型

- 类型：单选
- 必填：是
- 选项：
  - 功能异常
  - 界面或交互问题
  - 安装或启动问题
  - 性能问题
  - 功能建议
  - 翻译问题
  - 购买与授权
  - 其他

### 2. 问题标题

- 类型：单行文本
- 必填：是
- 提示：请用一句话描述问题，例如“切换主题后设置页按钮颜色未更新”。

### 3. NYAWORKS 版本

- 类型：单行文本
- 必填：是
- 默认提示：可在“设置 → 关于”中查看，例如 0.1.0-alpha.1。

### 4. After Effects 版本

- 类型：单行文本
- 必填：是
- 提示：例如 After Effects 25.5.0。

### 5. 操作系统

- 类型：单选
- 必填：是
- 选项：
  - Windows 11
  - Windows 10
  - 其他

### 6. 问题出现频率

- 类型：单选
- 必填：是
- 选项：
  - 每次都会出现
  - 经常出现
  - 偶尔出现
  - 只出现过一次
  - 无法确定

### 7. 复现步骤

- 类型：多行文本
- 必填：功能异常、界面交互、安装启动和性能问题时必填
- 提示：
  1. 打开了哪个页面或项目。
  2. 点击了什么按钮或执行了什么操作。
  3. 问题在第几步出现。

### 8. 预期结果

- 类型：多行文本
- 必填：是
- 提示：你原本希望看到什么结果？

### 9. 实际结果

- 类型：多行文本
- 必填：是
- 提示：实际发生了什么？如果有报错，请完整粘贴。

### 10. 附件

- 类型：文件上传
- 必填：否
- 建议格式：PNG、JPG、GIF、MP4、ZIP、JSON
- 提示：可上传截图、录屏、精简后的测试工程或“设置 → 关于 → 导出诊断信息”生成的文件。

### 11. 是否可以稳定复现

- 类型：单选
- 必填：是
- 选项：
  - 可以
  - 不可以
  - 不确定

### 12. 联系方式

- 类型：单行文本
- 必填：否
- 提示：可填写邮箱、飞书或其他联系方式，仅用于进一步确认问题。

### 13. 隐私确认

- 类型：勾选
- 必填：是
- 文案：我已检查提交内容，不包含不希望提供的项目文件、账号密钥、API Key 或其他敏感信息。

## 建议的条件逻辑

- 选择“功能建议”时，可隐藏 After Effects 版本、问题频率和复现步骤，增加“建议解决的痛点”字段。
- 选择“购买与授权”时，增加“订单号或授权邮箱”字段，并提示不要填写密码、验证码或完整支付信息。
- 选择“翻译问题”时，增加“当前语言”和“原文位置”字段。

## 提交成功提示

提交成功，感谢你的反馈。

如果问题能够稳定复现，请保留相关工程、截图和诊断文件，开发者可能会通过你填写的联系方式进一步确认。

## 管理建议

- 飞书多维表格字段建议增加：处理状态、优先级、负责人、目标版本、是否复现、关联提交。
- 处理状态建议使用：待确认、已复现、处理中、待验证、已完成、暂不处理。
- 不要公开展示其他用户的提交内容。
- 对外发布前先用未登录浏览器测试一次表单权限和附件上传。
