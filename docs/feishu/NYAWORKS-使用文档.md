# NYAWORKS / 喵创使用文档

> 适用版本：0.1.0-alpha.1  
> 产品阶段：早期开发预览  
> 适用平台：Adobe After Effects CEP 扩展

## 1. 产品简介

NYAWORKS / 喵创是一款面向 Adobe After Effects 的高频创作工具合集，目标是把常用操作、增强工具、资源管理和 AI 辅助能力集中到一个统一面板中。

当前版本主要用于确认扩展框架、主题、语言、首页布局和设置中心。首页工具与多数功能页仍在逐步开发中，尚未完成的入口会明确显示为占位状态。

## 2. 当前已完成

- 五套暗色主题，可即时切换并自动保存。
- 简体中文、繁體中文、English、日本語、한국어五种界面语言。
- 首页视觉框架、搜索入口和快捷工具区域。
- 常规设置，包括启动页面、界面与图标大小、界面亮度、提示和动效选项。
- 新功能提示与 GitHub Releases 版本检查。
- 关于页面、诊断信息导出和 AE 版本检测接口。

## 3. 当前尚未完成

- 首页快捷工具的真实 After Effects 操作。
- AI、项目、合成、图层、动画、文字、图形、效果和媒体功能页。
- 商业授权、设备管理和在线激活。
- 视频教程、官方网站和正式安装包。

这些入口可能已经出现在界面中，但会标记为“尚未接入”或占位状态。

## 5. 顶部快捷入口

### 新功能

点击铃铛按钮可查看当前版本的更新内容。存在尚未阅读的新功能时，按钮会显示提示标记。

### 主题

- 左键：按照固定顺序快速切换五套主题。
- 右键：展开主题列表并直接选择。

主题顺序：

1. 极夜青（默认）
2. 星云紫
3. 熔金琥珀
4. 翡翠深海
5. 樱夜绯粉

### 语言

- 左键：在简体中文与 English 之间快速切换。
- 右键：展开全部语言列表。

选择繁體中文、日本語或한국어后，按钮分别显示“繁”“あ”“한”。

### 设置

左键进入设置中心。设置中心目前包含常规、首页、AI、资源和关于五个分类，其中未完成的分类会明确显示占位说明。

## 6. 常规设置

### 启动与行为

- 启动页面：选择下次打开扩展时默认显示的页面。
- 记住上次页面：开启后优先恢复上次离开时的页面。
- 自动检查更新：启动时检查 GitHub Releases 是否存在新版本。

### 界面与图标

可选择大、中、小三档界面密度。该选项只调整控件、图标和间距，不改变首页功能结构。

### 交互与提示

- 鼠标提示：控制是否显示 Tooltip。
- 提示延迟：调整 Tooltip 出现速度。
- 界面动效：控制界面切换和状态反馈动效。
- 新功能提示：控制是否显示版本更新提示。
- 危险操作确认：执行删除、重置等高风险操作前进行确认。

### 外观与主题

- 当前主题：直接选择五套主题。
- 当前语言：直接选择五种界面语言。
- 界面亮度：在当前主题基础上调整整体明暗，不会替换主题配色。
- 首页 Banner：控制首页品牌 Banner 是否显示。

### 重置所有设置

恢复默认主题、简体中文、中等界面密度和默认常规设置。该操作不会删除用户资源或未来保存的 API Key。

## 7. 更新机制

“自动检查更新”开启时，扩展会在启动后检查 GitHub Releases。

- 检测到新版本：显示更新提示，用户可以选择查看更新或暂不更新。
- 选择暂不更新：本次关闭，下次启动仍会提醒。
- 关闭自动检查更新：启动时不再主动提醒。
- 安装新版本：当前版本对应的更新提醒结束。

当前阶段只打开安全的版本发布页面，不会在扩展内部自动下载或安装文件。

## 8. 关于与诊断

关于页面用于查看：

- NYAWORKS 当前版本。
- 当前连接的 After Effects 版本。
- 授权状态和商业化接口状态。
- 更新渠道。
- 使用文档与问题反馈入口。
- 扩展 ID、当前语言和本地数据说明。

“导出诊断信息”会生成用于排查问题的 JSON 文件。“打开数据目录”仅在真实 After Effects CEP 环境中可用。

## 9. 数据与隐私

- 主题、语言和常规设置默认保存在本机。
- 当前 AI 功能尚未接入，不会上传 AI 对话或 API Key。
- 诊断信息仅在用户主动导出后生成。
- 提交问题反馈前，请检查截图和诊断文件中是否包含不希望公开的项目名称、文件路径或个人信息。

## 10. 常见问题

### 为什么部分按钮不能点击？

该功能尚未接入，界面仅保留产品结构和后续开发入口。

### 浏览器预览为什么显示“未连接 AE”？

浏览器预览无法访问 After Effects 宿主。只有扩展运行在真实 AE CEP 环境中时，才能读取 AE 版本和打开扩展数据目录。

### 切换主题或语言后需要重启吗？

不需要。主题和语言会立即生效并保存在本机。

### 检查更新失败会影响扩展使用吗？

不会。网络不可用、请求失败或 GitHub 没有发布版本时，更新检查会保持静默。
