# 伪效果生成基底

`base-scribe.ffx` 是 Tomas Šinkūnas 的 `rendertom/PseudoEffect` 项目中 MIT 授权的 Scribe 样例，授权文本见 `LICENSE-rendertom.txt`。它只作为 `scripts/build-rounded-rectangle-pseudo.mjs` 的制作输入，不是 NYAWORKS 的圆角矩形成品，也不随 CEP 扩展打包。

当前用于新建圆角矩形的参数规格位于 `../v2/schema.json`；生成的唯一交付文件为 `public/host/pseudo-effects/rounded-rectangle-zh-CN.ffx`。错误的旧圆角矩形候选已移除，Git 历史中仍可查阅其制作过程。
